# iOS 原生系统导航

在“设置 → 底部导航栏管理 → 原生系统导航”中选择系统导航或原有自定义 Dock。iOS 26 及以上默认使用系统导航；旧系统、其他平台及原生通道不可用时继续使用自定义 Dock。

## 可调参数

| 参数 | 范围 / 行为 |
|---|---|
| 使用系统导航栏 | 可随时切回自定义 Dock，原有外观偏好保留 |
| 显示标签文字 | 关闭后保留 VoiceOver 标签 |
| 强调色跟随主题 | 可关闭并选择紫、蓝、绿、橙、粉 |
| 图标大小 | 18–30 pt；最终尺寸仍由系统布局适配 |
| 左右留白 | 0–40 pt；窄屏自动限制边距，保证导航项空间 |
| 安全区上方距离 | 0–32 pt；在系统安全区上方增加距离 |

设置页在支持的设备上显示原生组件预览。参数实时生效，开关立即保存，滑块松手保存；恢复按钮只重置这组原生参数。系统材质、选中透镜、折射和动效由 UIKit 管理，原有“外观与材质 / 液态玻璃细调”继续控制自定义 Dock。

## 收起与隐藏

- 展开时，默认同一胶囊内依次为“漫画 / 视频 / 设置 / 搜索”。搜索固定在最右侧，不再预留独立圆形搜索按钮的位置。
- 搜索沿用当前漫画、普通视频或猫源的搜索流程，保留当前内容页及选中状态；在设置页点击时先选搜索漫画或视频。页面仍在加载时暂存一次搜索请求，当前可见页面就绪后接收，隐藏的视频面不会抢走回调。
- 滚动收起时，四项共同收成左侧展开按钮；点击或向右滑后恢复完整胶囊。
- 进入阅读器、播放器或全屏路由时，导航与搜索一同隐藏；返回后一起恢复。
- 键盘出现时一同隐藏。键盘状态由导航壳向下传递，避免子页面 Scaffold 移除 viewInsets 后搜索按钮残留。
- 标签隐藏、排序、隐藏设置后的恢复入口继续使用原有规则。

## 实现

`ios/Runner/LumeSystemTabBar.swift` 提供真正的 `UITabBar` 平台视图，使用 SF Symbols。平台视图仅占导航栏区域，不替换 FlutterViewController，不创建额外引擎，不改变页面及播放器的生命周期。Flutter 仍按原有标签 ID 切换页面，并用原有 ShellDockController 管理显隐。

`lib/features/shell/system_dock_bar.dart` 同步标签、选中项、主题与参数，接收原生选择事件及系统栏高。隐藏时移除平台视图及事件处理器；原生更新失败时回退自定义 Dock。没有设置额外的 UITabBarAppearance 来覆盖系统玻璃。

`shell_settings.json` 新增独立的 `nativeNavigation` 配置。旧配置的标签顺序、可见性、收起样式和 Dock 外观保持原值；原生参数不会被修改标签或自定义材质时覆盖。

这里采用独立 UITabBar。搜索使用普通 UITabBarItem，放在同一个系统胶囊中；didSelect 将搜索转交当前内容页并恢复原选中项。Flutter 自定义 Dock 同样将搜索作为第四项，点击后保持当前内容的选中位置。原有三个内容页的排序与隐藏偏好继续保留，设置预览也包含固定的搜索项。
