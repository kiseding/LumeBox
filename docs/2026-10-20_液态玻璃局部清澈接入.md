# 液态玻璃第一轮实现：底座局部清澈与取样顺序

- 日期：2026 年 10 月 20 日（北京时间）。
- 对应方案：`docs/2026-10-19_前期交流功能进度与待办.md` 第 5.3 节第 1、2 条（整理背景取样与合成顺序、把变清澈的范围改为局部）。
- 参考帧核对报告：`docs/2026-10-20_液态玻璃参考帧核对.md`（5.6 第 1 条待办已完成）。
- 本轮只改底部 Dock 的底座取样与清晰区域；整体升级、导航合并、图标主题均未改动。iOS 真机效果仍待新 IPA 验收。

## 1. 解决的核心问题

改造前底座与透镜都从“已经被 Dock 处理过的画面”取样：

1. 底座 `BackdropFilter` 先把页面整条模糊、叠白；
2. 水滴（选中圆片）再模糊一次；
3. 透镜最后采样，拿到的是已经糊过两遍的画面。

因此按住时只能靠“降低整条底座模糊 / 白度”来表示清澈，细节在第一次模糊时已经丢失，透镜区域也无法恢复。

本轮把一次底座模糊 + 局部遮罩合成为一个 `ImageFilter`：

```text
BackdropFilter(
  filterConfig = ImageFilter.compose(
    outer: FragmentShader(遮罩 + 白度),   // 引擎对原始页面先做 inner blur
    inner: ImageFilter.blur(sigma = 磨砂强度),
  ),
)
```

- 遮罩 shader 在透镜区域把磨砂层压到很低的 alpha（`_lensCoreAlpha = 6%`），**原始页面直接从下面透出来**，因此透镜再采样时是清晰的；
- 透镜仍画在图标/文字之后，所以图标与文字继续被放大、折射；
- 过渡带使用 smoothstep，清澈区跟随透镜连续移动，边缘没有硬切；
- 回退路径（Skia / 不支持 `ImageFilter.shader` 的后端）保持旧行为：整条底座模糊，按压时降低磨砂与白度，观感与改造前一致。

关键文件：

| 文件 | 变更 |
| --- | --- |
| `assets/shaders/dock_liquid_surface.frag` | 新增：底座遮罩 + 白度合成 shader（`u_size`、`u_lens`、`u_shape`、`u_glass` 四个 uniform 块） |
| `lib/features/shell/dock_liquid_surface.dart` | 新增：`DockLiquidSurface` 与 `DockLiquidSurfaceFilter`；加载 shader、失败回退、按绘制时的舞台原点对齐透镜矩形 |
| `lib/features/shell/shell_dock_bar.dart` | 重构底座/内容几何：抽出 `_DockGeometry`，让底座遮罩与透镜共用同一矩形；底座改为 `DockLiquidSurface`；水滴在清澈时不再二次模糊；回退路径保留原公式 |
| `test/dock_liquid_surface_test.dart` | 新增：回退入口回归；Impeller 下断言“透镜内清晰、其余区域磨砂” |
| `tool/dock_surface_preview_test.dart` | 新增：开发期预览，输出静止/按住/拖动/松手截图 |

## 3. 与参考录屏的差异（下一轮）

参考帧测量结论（详见参考帧核对报告）与本轮预览对照后，仍有以下差距：

1. **透镜中心亮度不足。** 参考透镜内 58% 像素接近纯白（L ≥ 250），彩色内容只透 30–40% 色度；当前实现接近“清晰窗”，背景对比过强。下一轮在透镜 shader 内加中心提亮/降饱和，并保留清晰细节。
2. **边缘色散偏强。** 当前黑白高频背景下彩虹边很明显；参考的色散更克制（白底几乎为 0，彩色背景才出现）。需要按背景饱和度自适应或整体降低幅度。
3. **透镜尺寸与投影。** 参考透镜宽约底座 28–31%、高约底座 1.20–1.24 倍、上下各越出底座 4.3–6.3 pt，且投影比底座更深；当前透镜宽度约 21%、下沿越出偏多，投影偏浅。
4. **按压几何。** 参考录屏中按压是“整条底栏含图标文字一起放大 ~3.4% + 变白”，**没有测到真实收腰**；当前实现只缩放底座、图标不动，且原方案中的“局部收腰”被测量否定。下一轮建议改为整条统一缩放 + 提亮，收腰最多作为可选/关闭的附加效果。
5. 背景颜色联动、规则/自由形状、设置项与旧参数迁移、真机性能均未开始。

## 4. 风险与限制

- `ImageFilter.shader` 只在 Impeller 后端可用：iOS 走新路径，Windows 桌面与 Skia 测试渲染器走回退路径（旧观感）。新路径的真机手感与实际光学仍需 IPA 验收。
- Impeller 的 OpenGLES 后端存在 y 轴方向差异的已知约束；本轮未在 GLES 设备上验证遮罩方向，iOS（Metal）与 Vulkan 模拟器已通过截图检查。
- 底座现在每帧都会执行一次 blur + shader 合成（有动画时）；静止时没有额外动画更新，但滚动背景仍会触发重绘，需在真机 Profile 下测帧耗时。
- 旧参数 `blurReduction` / `opacityReduction` 在 Shader 路径下含义已变为“清澈强度 / 核心白度”，回退路径保持旧含义；设置文案与迁移在下一轮统一处理，避免现在改一半。

## 6. 2026-10-20 第三轮：背景明暗联动与新增设置参数

### 6.1 背景明暗联动（5.3 第 5 条的第一部分）

底座 shader 读取局部背景亮度（模糊采样本身已包含颜色信息，不需要额外读取整屏像素）：

- 背景越暗，玻璃白度越高（最高 ×1.25），保证图标/文字在深色海报上的对比度；
- 背景越亮，回到用户设定的白度（×1.0），避免整条变成更厚的白板；
- 亮度到白度的映射用 smoothstep 连续过渡，滚动或切换内容时不会整条闪白；
- 强度由新参数“背景明暗联动”（默认 50%）控制，0% 时完全回到固定白度。

### 6.2 新增设置参数（5.4 的部分落地）

新增 5 个参数，按原有分组自动出现在“设置 → 底部导航栏管理 → 液态玻璃细调”（`DockLiquidParameter` 枚举驱动，未改设置页结构）：

| 参数 | 默认 | 范围 | 分组 |
| --- | --- | --- | --- |
| 透镜中心提亮 | 42% | 0–100% | 透镜折射 |
| 透镜中心降饱和 | 30% | 0–100% | 透镜折射 |
| 清澈过渡宽度 | 30% | 5–60% | 按压变清透 |
| 透镜核心玻璃厚度 | 6% | 0–50% | 按压变清透 |
| 背景明暗联动 | 50% | 0–100% | 高光与阴影联动 |

旧的透镜提亮/降饱和、过渡宽度、核心厚度与背景联动硬编码值已替换为参数；`DockLiquidSettings.fromJson` 对缺失字段补默认值，旧配置不会被覆盖。“恢复液态参数默认值”会一并恢复这些新参数。

验证：`flutter analyze` 无问题；Skia 全量 2023 项通过、13 项跳过；新参数默认值/旧配置迁移断言加入 `test/dock_liquid_interaction_test.dart`；预览见 `build/dock-surface-preview/gpu-page-idle.png` 与 `gpu-stripes-idle.png`（亮/暗背景下的白度差异）。

## 7. 2026-10-20 第四轮：规则形状与自由形变（5.3 第 4 条）

### 7.1 基础形状

`DockLiquidSettings` 新增 `shape`（`DockLensShape`：胶囊／圆角矩形／椭圆／圆形）与 `freeDeform`，以及 3 个参数：

| 参数 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| 形状宽度 | 100% | 60–150% | 选中底座/透镜的宽度倍率 |
| 形状高度 | 100% | 60–150% | 鼓起后的高度倍率 |
| 圆角程度 | 100% | 0–100% | 仅圆角矩形：100% 接近胶囊，0% 接近直角 |

实现要点：

- `_DockGeometry` 统一把形状倍率应用到水滴/透镜矩形；圆形会自动把宽高收为同一直径，避免椭圆化；
- 新增 `_dockLensPath` 统一生成路径：圆形/椭圆为椭圆路径，圆角矩形为可调圆角 RRect，胶囊用原有水滴路径；
- 底座清澈遮罩仍按透镜矩形近似（圆/椭圆时为外接矩形），因此局部清澈区域与透镜位置保持同步；
- 点击目标仍是整条页签槽位，形状只影响视觉，不改变页签宽度与排序。

### 7.2 自由形变开关

- `freeDeform` 关闭时：`_stretchFraction` 与拖动宽度倍率强制为 0，胶囊严格保持 stadium、圆角矩形保持规则圆角，透镜不倾斜、不拖尾；
- 开启时（默认）：保留原有速度/拉力驱动的拉伸、拖尾与倾斜；
- 形状与自由形变互相独立：圆形/椭圆始终规则，胶囊/圆角矩形才叠加自由形变；
- 设置页新增“基础形状”分组：形状 ChoiceChip + 自由形变开关 + 3 个形状参数，切换后上方真实底栏预览立即生效。

验证：`flutter analyze` 无问题；Skia 全量 2024 项通过、13 项跳过；新增“圆形保持正圆、自由形变关闭不拉伸”用例与旧配置迁移断言；预览见 `build/dock-surface-preview/shapes-sheet.png`（胶囊/圆角矩形/椭圆/圆形）与 `gpu-page-*`。

## 8. 2026-10-20 第五轮：按压几何按参考实测改写（5.3 第 3 条的替代实现）

参考帧核对报告确认：按压时底栏是整条放大（宽 1197→1238、高 187.7→195，约 ×1.034/×1.039，中心不动，图标文字同步放大）并变白，没有测到真实收腰。本轮按该结论改写按压几何：

| 改动 | 内容 |
| --- | --- |
| 整条缩放 | `_DockGeometry` 新增 `wholeScale = 1 + 按压放大比例 × press`；`_buildCapsule` 把原来只包底座的 Transform 改为包住整个 Dock（底座 + 图标文字 + 水滴 + 透镜），默认放大 3.4% |
| 按压提亮 | 新增参数“按压整体提亮”（默认 18%）：Shader 路径提高底座 tint 透明度；回退路径在原按压减弱公式后叠加提亮，全白端点保持全白 |
| 原胶囊伸缩 | “胶囊横向/纵向伸缩”默认降为 0，作为辅助效果保留；去掉了底座单独倾斜/位移 |
| 清澈遮罩跟随缩放 | 新增 `lensScale` 传入底座滤镜，遮罩矩形的偏移、尺寸、圆角与过渡带都按整条缩放同步放大，避免按住时清澈孔比透镜小一圈 |
| 收腰 | 按实测**不实现真实局部收腰**；截图里的“内收”由透镜台阶、透镜投影和边缘变淡造成 |

新增参数（默认值）：整条按压放大 3.4%（范围 0–8%）、按压整体提亮 18%（范围 0–40%），均归入“胶囊联动”分组。

测试更新：

- 新增“按压时整条底栏与图标文字一起放大”：用两个页签中心的实际距离断言约 ×1.034；
- “白度端点”用例改为符合参考的行为：全白端点按压后仍为 1；全透端点按压时会被提亮（不再保持 0），并限制在提亮上限内；
- 形状/透镜/设置相关用例全部保持通过。

验证：`flutter analyze` 无问题；Skia 全量 2025 项通过、13 项跳过；Impeller 预览与参考按住帧对照见 `build/dock-surface-preview/compare-reference-vs-new.png`。

### 9. 2026-10-20 第六轮：预设、分组与迁移收尾（5.4）

### 9.1 三套预设

`DockLiquidPreset` 提供三套一键组合：

| 预设 | 组合 |
| --- | --- |
| 推荐 | 当前默认值（胶囊 + 自由形变 + 3.4% 整条放大 + 18% 按压提亮） |
| 规则通透 | 规则胶囊、关闭自由形变、清澈强度拉满、过渡带更窄、核心更透、色散降到 20% |
| 柔和自由 | 圆角矩形（圆角 70%）、自由形变开启、中心更白、过渡更宽、色散更明显、整条放大降到 2% |

预设只替换 `DockLiquidSettings`（形状、自由形变、液态参数与效果开关），不触碰导航尺寸、排序、主题、图标与白度/磨砂等外观字段；可序列化后在重启时原样恢复。“恢复液态参数默认值”回到“推荐”。

### 9.2 分组整理

“液态玻璃细调”页重排为：预设 → 基础形状（形状 ChoiceChip + 自由形变开关 + 形状宽度/高度/圆角程度）→ 跟手与回弹（按压响应时间、回弹阻尼）→ 效果与材质（六类效果开关 + 各自参数）。原有 Key（`dock-liquid-<参数>`、`dock-liquid-effect-<效果>`、`dock-liquid-reset`）保持不变，新增 `dock-liquid-preset-<预设>` 与形状/自由形变 Key。

### 9.3 旧参数迁移

- 旧外观配置缺字段时补默认值：新增形状、自由形变、按压放大/提亮、材质参数都走 `fromJson` 的安全默认；
- `blurReduction` 在 Shader 路径下表示清澈强度（默认 62% 视作满强度），`opacityReduction` 只作用于回退路径的原有减弱；文案已在调节说明中更新；
- 预设与“恢复默认值”都不清空导航顺序与其他个人设置；
- 管理页测试同步改为滚动到按压响应时间，适配新的分组顺序。

## 10. 2026-10-20 第七轮：可选的局部收腰、性能/辅助功能收尾与验证矩阵

### 10.1 局部收腰（默认关闭的附加效果）

参考帧核对没有测到真实收腰，因此没有把它做成默认行为，而是新增参数“局部收腰”（默认 0%，范围 0–100%，归入“胶囊联动”）：

- 参数为 0 时底座保持规则胶囊，旧的 `ClipRRect` 路径不变；
- 大于 0 且正在按压时，用 `_dockWaistPath` 在胶囊上/下缘按触点位置切出两个浅椭圆缺口，深度随按压进度与参数连续变化，松手回到规则轮廓；
- 收腰只裁剪底座轮廓，透镜、点击区域与页签宽度不受影响；
- `DockLiquidSurface` 新增可选 `clipPath`：为空时仍走原圆角矩形裁剪，避免影响默认性能与视觉；
- 预览对照：`build/dock-surface-preview/waist-comparison.png`（默认 vs 收腰 100%）。

## 11. 2026-10-20 第八轮：Flutter 自绘 / iOS 原生材质 A/B 开关

为了在真机上直接对比两条路线，设置页新增“渲染方式（A/B 对比）”：

| 选项 | 实现 | 说明 |
| --- | --- | --- |
| Flutter 自绘（默认） | 现有 Shader 方案 | 取样、局部清澈、透镜折射、色散、整条按压放大等全部保留 |
| iOS 原生材质 | `UiKitView` + 原生 `UIVisualEffectView` 系统材质 | iOS 26 上系统材质自动采用 Liquid Glass 外观；底座交给系统渲染 |

实现要点：

- Dart 侧：`DockLiquidSettings.glassRenderer`（默认 `flutter`，可序列化；旧配置缺字段自动补默认）+ `DockNativeGlass` 平台视图；设置页新增 ChoiceChip（`dock-glass-renderer-*`），预设应用不会重置渲染方式。
- **原生材质也带可调参数页**：选择“iOS 原生材质”后，细调页出现“原生材质参数”分组——
  - 原生材质风格：清透（`systemUltraThinMaterial`）／标准（`systemMaterial`）／厚实（`systemThinMaterial`），切换时通过 `lumebox/glass_backdrop_<viewId>` 通道实时更新，不需要重建平台视图；
  - 原生材质白度（`nativeTint`，默认 6%，范围 0–35%）：叠在系统材质上的 Flutter 薄层，实时生效；
  - 形状、白度、磨砂、按压放大、整体提亮、阴影等通用参数继续生效；透镜折射/清澈参数在原生模式下不生效并有提示。
- 原生侧：新增 `ios/Runner/LumeGlassBackdrop.swift`（`FlutterPlatformViewFactory`，系统材质 + 圆角 + 更新通道），在 `AppDelegate.didInitializeImplicitFlutterEngine` 注册 `lumebox/glass_backdrop`；已加入 Xcode 工程 Sources 与 CI 的 Swift typecheck 列表。
- 回退：非 iPhone 平台选择原生材质会自动回退 Flutter 自绘，不会崩溃；设置页会提示“当前设备不是 iPhone”。
- **已知限制**：Flutter 平台视图不能参与 `BackdropFilter` 取样，因此原生材质模式下会关闭自绘透镜的折射/清澈遮罩（水滴改为纯色填充），只保留原生底座、图标文字、拖动形变与描边。这是“原生材质底座 + Flutter 内容层”，不是完整的原生 TabBar；若原生路线胜出，下一步才评估是否把整个底栏换成原生。

验证：`flutter analyze` 无问题；Skia 全量 2031 项通过、13 项跳过；新增渲染方式/原生材质参数迁移、非 iOS 回退、设置页切换用例。Swift 编译需 CI 校验；本轮未打 IPA。

## 12. 2026-10-20 第九轮：剩余细节补齐

### 12.1 辅助功能降级

| 场景 | 处理 |
| --- | --- |
| 系统“减少动态效果” | 既有逻辑：按压/拉伸/回弹/收腰/透镜全部不启动（已有用例） |
| 系统“降低透明度” | iOS 通过 `lumebox/accessibility` 方法通道读取 `UIAccessibility.isReduceTransparencyEnabled`；开启时底座白度提到约 90%、关闭透镜清澈区、原生模式提高原生材质白度；设置页也提供手动开关“减少透明效果” |
| 系统“增强对比度” | `MediaQuery.highContrast` + iOS `isIncreaseContrastEnabled`：描边高光增强约 1.8 倍、关闭边缘色散 |
| 大字号 | 字号继续走 `InterfaceTextScaler`；底座高度与图标/文字布局沿用既有自适应 |

### 12.2 背景颜色与光影联动

- 底座 shader 在原有“明暗联动”之外增加**饱和度联动**：高饱和背景降低白色覆盖，保留背景色相，避免彩色海报被统一洗成灰白；暗背景仍提高白度保住文字对比度。
- 透镜高光方向随拖动方向/上下跟手偏移：高光不再固定左上，拖动时随 `u_motion` 轻微转向。

### 12.3 自由形变补齐

- 胶囊/圆角矩形在拖动时新增一个很小的**方向性倾斜**（沿拖动方向剪切，幅度约 3.5%，随拉伸量缩放），与拉伸、拖尾一起构成“倾斜 + 拉伸 + 拖尾”的连续形变；关闭自由形变时全部归零。
- 边缘起伏仍通过路径的外鼓/尾巴表达，未加入随机抖动（避免像故障效果）。

- Impeller 预览：`tool/dock_surface_preview_test.dart` 重新生成；本轮开始进入真机 IPA 验收（见下）。
