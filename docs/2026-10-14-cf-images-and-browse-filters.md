# CF 会话、封面与筛选修正

用户反馈：JComic 有列表却无封面；MYCOMIC、漫蛙通过网页验证仍返回 403；禁漫天堂首页持续加载。筛选栏存在多排重复入口。

## 证据与改动

- 2026-10-14 实际 HTTP 检查：JComic 分类页 200，其独立 images.jcomic.net 签名封面返回 Cloudflare Attention Required 403，带与不带 Referer 均被拦截。不能把主站已验证等同于图片域名已验证。
- 已验证源的无代理 GET 使用 iOS URLSession 和域名、路径约束下的 WebKit Cookie；403 时保留原有 WebKit 页面读取，并等待导航完成，避免 didCommit 后 150ms 立即返回挑战页。
- 图片遇到明确 CF 拦截时使用同一图片 origin 的 WebKit fetch；仅使用浏览器自己的 same-origin 凭据，不向图片域名复制源站 Cookie。仍被拦截则显示独立图片验证入口，不进行无效自动重试。
- 图片验证手动窗口保存 WebKit 自身 Cookie；不覆盖主站 Cookie 串。非 CF 防盗链 403 继续原有 Referer 重试规则。
- 首页和列表 40 秒后返回可重试超时，原请求晚返回不覆盖当前界面。
- 总分类行使用一个 tune 图标，下面筛选行删除各自入口；统一面板支持搜索、重置、一次应用分类与各组选项。

## 验证范围与限制

Flutter 回归验证二进制 WebKit 通道、图片域名挑战识别、Cookie 隔离及 375 像素宽统一筛选面板。iOS Swift 在构建工作流中编译验证。

本机漫蛙和禁漫天堂普通请求仍被 CF 拦截。代码测试不等于手机验证会话已通过；最终需手机上的真实验证会话确认首页、封面和章节。不会宣称三个站点全部恢复，不关闭证书校验，不绕过验证码或付费限制。
