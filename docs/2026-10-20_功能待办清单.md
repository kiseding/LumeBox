### ✅ P1 · 已完成（待真机验收）

- **播放器偏好接线**：UA 已接到播放请求头；字幕语言自动选择；详情页“只选中不播放”生效。
- **网页主页源**：选择器可添加/编辑/删除主页，内置 WebView 打开与返回，记录最后使用的主页。
- **猫源 parse=1**：网页解析页嗅探媒体地址并交给播放器，失败保留直连回退。

### P1 · 播放器偏好接线（已完成，待真机验收）

- **现状**：浏览器 UA、字幕语言、详情页“只选中不播放”可以保存，但没有接到实际运行行为。
- **目标**：
  - UA 真正传给内置播放器和网页视图；
  - 字幕语言用于选择默认/首选字幕轨；
  - “只选中不播放”在详情页只高亮选集、不自动起播。
- **验收**：改设置后无需重启立即生效；失败时回退默认值；现有播放器回归通过。
- **规模**：小。

### P1 · 网页主页源（已完成，待真机验收）

- **现状**：视频源选择器已有“网页”分类和添加入口，点击提示未接入。
- **目标**：保存/编辑/删除主页地址；添加订阅后出现在选择器；点击打开内置 WebView 主页；返回 App 时状态保留；支持多个主页源与排序。
- **验收**：新增、编辑、删除、重启保留；打开/返回不丢页面；无网络/错误页有提示。
- **依赖/风险**：WebView 会话与 Cookie 已有基础；需要确认主页源与现有普通源/猫源的展示顺序。
- **规模**：中。

### P1 · 猫源 parse=1 网页解析（已完成，待真机验收）

- **现状**：猫源返回网页解析地址（parse=1）时提示换直连线路，网页解析未接通。
- **目标**：识别 parse=1 地址 → 打开内置 WebView/解析接口 → 提取真实播放地址 → 交给播放器；失败时保留现有直连回退与提示。
- **验收**：至少覆盖两个真实猫源站点；解析失败可回退；不阻塞其他播放路径。
- **依赖/风险**：站点反爬、验证码、Cookie；不同站点解析规则差异。
- **规模**：中。

### ✅ P2 · 通用 Python 源（代码完成，待真机与真实站点验收）

- **已接入**：嵌入式 CPython、文件／订阅／剪贴板导入、PY 分类、Spider 与 get 前缀别名、参数签名适配、搜索／分类／详情／多线路选集／播放、网页解析回退。
- **通用兼容**：Requests、urllib、http.client、HTTPX、BeautifulSoup、常用 XPath／PyQuery 接口、常见 AES／ChaCha／摘要接口、GBK 等编码声明、缺失依赖与 Android 专属能力提示；适用范围由接口和依赖决定，不按五份文件名定制运行时。
- **验证**：五份用户脚本均通过原文件加载与分类检查；金牌／影探4K 通过离线应答下的完整播放地址链路。算法另有已知向量测试。
- **剩余**：真实站点与 iPhone 起播、后台及会话验收。任意第三方客户端私有接口、原生扩展、Android Java／DEX、本地代理服务不能宣称全面兼容。
- **说明**：[Python 与模块源接入](2026-10-20_Python与模块源接入.md)。`1.0.171` 不含本次代码，按约定未出新 IPA。
- **工程验收**：Flutter 全量 2053 通过／13 跳过，新增网络桥用例 2 项通过；静态分析无问题；[iOS 原生与模拟器校验](https://github.com/teng662858/LumeBox/actions/runs/39407193057)成功（模拟器内 Python 套件 10 项通过）。

### ✅ P2 · 单文件 JS 模块源（代码完成，待真机验收）

- **已接入**：文件／订阅导入、模块分类、宿主网络与存储、分类／搜索／详情／选集／播放、启停删除及备份恢复。

- **依赖/风险**：属于 APP 整体升级范围，用户已明确暂缓；等待范围确认，不排开发。
