# 播放页布局与连接诊断

播放页按横竖屏分别排列常用控件；横屏选集／线路与画质分别打开各自内容，沿用同一套紧凑面板样式。最低支持版本保持 iOS 16.0。

## 使用播放页

- 全屏顶部保留返回、片名与集名，实际分辨率位于片名下方、集名后面，同一行显示如 `第1集 · 1920×800`；没有集名时只显示内核提供的完整尺寸。长文案单行省略。该信息不可点击、未知时省略；不会按源标签推测或换成画质档位。
- 横屏底部左侧为播放／暂停、下集，右侧固定为文字入口「弹幕」「1.0×」「选集」。上一集仍可在选集面板选择。窄屏保留播放与三个文字入口，适当缩小可见文字，点击框保持至少 44。
- 画质从「播放器设置 → 播放与选集 → 画质」进入，只显示片源实际提供的选项；没有多档时说明原因。全屏选集面板只包含选集与线路，不再混入画质。播放内核收进设置的「内核与网络」。
- 时间与已知电量位于全屏顶边独立的一行：时间靠左，电量百分比与电池图标靠右，下面才是返回、片名与操作按钮。状态行保留系统安全区，并随控制栏一起收起；电量未知时省略电池与百分比。iOS 与 Android 均读取系统真实电量。传输速率移到进度条右上方的小字，通过设置「内核与网络 → 显示播放速率」开关控制并记住选择。技术参数仍可在播放信息查看。
- 片头片尾标记收进播放器设置的「片头片尾」，有效跳过提示仍独立出现在画面上。
- 横屏面板按安全可用宽度约 34% 布局，通常为 260–320 逻辑像素。竖屏默认占可用高度的 60%，通过顶部箭头或拖动把手展开到约 85%；键盘打开时同时避让。
- 选集面板自动定位当前集，支持正倒序、每 50 集分段以及按序号定位。长标题和较大字号使用更少列数，保留完整标题提示。
- 「线路」只允许切到可唯一匹配的对应集；缺集或匹配不明确时禁用该线路。切换线路或画质保留当前时间与暂停状态，失败时保留面板重试出口。
- 播放地址位于右上角「播放信息」图标弹出的信息卡，可复制，不提供手动粘贴地址起播。

## 快进/拖动延迟

- 拖动中每 150ms 发一次 `seekFast`（跳关键帧），松手再做一次精确 `seek`；
- 三套内核分别落地：AVPlayer 走原生 seek 容差（400ms，见 vendored 插件 PATCHES 补丁 2）、
  MPV 切 `hr-seek=no`、MDK 用 `fast|keyFrame` 标志；
- 松手后的确认等待从 2s 收到 800ms，避免「拖动到 xx」长时间挂起。

## 横屏左右边距

顶部、底部与左右侧的常驻按钮，点击框外缘距同侧安全区边界均为 8 逻辑像素（此前为 16，本轮每侧外移 8）；距物理屏幕边缘还需加上设备同侧的系统安全区。默认点击框至少 44，图标基准 21，居中图标框另有约 11.5 的内部留白；自定义控件缩放会影响图标内部留白，不改变外层的 8。

右侧选集／设置弹出面板距右侧安全区为 24，左侧最小保留安全区加 8。弹出面板本轮保留这些边距。

- 横屏贴边抽屉的工具条行贴到面板最顶（不再让出顶部安全区）；抽屉打开期间隐藏播放页自绘的电量与电池图标，避免从工具条图标底下透出来。
- 竖屏（沉浸直屏）：锁与横竖屏按钮放在屏幕下方三分之一处（距底 = 屏高/3），不再压住竖屏短剧人物；网速仍在进度条上方独立一行（受「显示播放速率」开关控制）；弹幕底部 reserve 110；进度条手柄 8、overlay 20；竖屏所有抽屉（选集、弹幕、播放器设置、倍速/内核菜单、播放信息以外的播放菜单）统一为：铺满屏宽、高度 40%（键盘弹出 85%），与横屏 40% 宽 × 满高的面积一致；取消竖屏抽屉顶部的展开抓手，选集卡片贴屏幕两边、工具条保留内边距，竖屏选集封面 36×64（9:16），横屏保持 94×56；
- 播放页提示不再用 SnackBar 黑条：改成画面顶部居中的半透明胶囊，1.6 秒自动淡出、新提示顶掉旧的，长文案最多两行。
- 弹幕层让开顶部 72 与底部 96（全屏时），不再压住片名与进度条；半屏各留 8。
- 单击画面切换控制栏（显示时立即收起），双击左右两侧各 27% 区域前进/后退 10 秒，中间单击不受双击延迟。
- 顶部片名由 titleSize+1 收到 titleSize，副标题由 captionSize+1 收到 captionSize 并降为 0xFFE4E4E4；全屏网速改为弱化样式（captionSize-1、半透明）。
- 全屏选集面板也提供「画质」分区；平台不支持画中画时不再显示 PiP 按钮。

全屏控制层行距收紧：状态行与片名块之间由 4 + 6 收到 2 + 2，片名整体上移约 6；进度行滑条盒高由 44 收到 34、控制栏顶部留白由 8 收到 4，进度行整体下沉约 6；最底部按钮行位置不变（已贴安全区）。

## 理解反馈

短暂缓冲小于 800 毫秒不显示加载层；持续等待 8 秒后提供重试与换线。获取剧集地址和切画质时显示具体操作名称。锁定状态不展示可误触的缓冲操作按钮。

拖动进度显示目标时间和前进／后退秒数。长按提示临时倍率及松手恢复倍率。总时长未知时禁止进度定位。手势说明可以从播放器设置重新查看。

片头片尾沿用现有识别、四点标记及同剧记忆。跳过提示仅在有效片段内显示，自动模式提供倒计时与取消；预览中的示例片段时间不会写进正式播放逻辑。

## 材质与平台

视频画面不参与整体模糊。控制层使用透明渐变和文字投影；玻璃开关开启时，底部控件共用一块玻璃背景。iOS 复用现有原生材质底座，iOS 26 起由已支持的 SDK 路径使用 UIGlassEffect，旧系统回退 UIBlurEffect；菜单使用较厚的 Flutter 磨砂以保证文字清楚。支持减少动态效果、提高对比度和降低透明度。

安卓模拟器可确认布局、触控、真实媒体起播与面板操作，不能确认 iPhone 的原生玻璃采样、HDR 亮度、杜比输出与系统画中画。这些需要 iPhone 真机验收。

## 排查 TMDB 测试失败

API 代理地址留空时，按钮为「测试 API 连接」，访问 TMDB 官方接口；有自定义地址时显示「测试 API 代理」。测试沿用全局 HTTP 代理设置。

失败提示区分 DNS、网络连接、超时、TLS、地址或内容格式，以及 HTTP 401／403／429。提示说明当前测试的是官方服务还是自定义服务、是否经过全局 HTTP 代理，不展示请求密钥。电脑网络可访问不代表手机网络可访问；不能仅凭旧版通用错误判断内置密钥失效。

## 本地验证与移动端预览

```powershell
flutter analyze --no-pub --fatal-infos lib test tool/android_player_preview.dart
flutter test --no-pub --reporter expanded
flutter build apk --debug --no-pub -t tool/android_player_preview.dart
```

移动预览入口是 `tool/android_player_preview.dart`，使用同一个正式播放页，并在预览入口单独注入 Android 系统的 video_player 解码后端；正式 App 的 iOS 平台可用性策略不变，安卓预览中 AVPlayer 这一选项不代表 Apple AVPlayer 的输出效果。通过 `tool/player_preview_server.py` 提供 `build/player-reference/` 中的原创测试媒体，并使用 `adb reverse tcp:8765 tcp:8765` 让模拟器访问本机。横屏、竖屏测试文件分别为 `player-fixture.mp4`、`player-portrait-fixture.mp4`。预览列表中的剧集与线路用于检验交互，不作为真实订阅发布。

测试覆盖短缓冲消失、长缓冲出口与锁定、异步切画质成功后关闭／失败后重试、线路缺集禁用、面板展开、横竖屏安全区、同剧片头片尾记忆、进度恢复与 TMDB 诊断。截图、媒体、构建产物和本机日志不随源码提交。
