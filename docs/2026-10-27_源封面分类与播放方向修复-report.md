日期：2026-10-27。范围：用户反馈的 91吃瓜视频/图集、127漫画、41看片，以及短剧入场方向；另对本地制源工坊截图中的浏览器跳转错误做了修复。本文为应用兼容性记录，未进行账号、付费或访问权限测试。授权依据为本次用户修复请求；未建立独立安全评估 case，scope.md 不适用。

## 观察、原因与修复

| 证据 | 结论 | 修复路径 |
|---|---|---|
| E1：91公开 `zzz.js` 的 `decryptImage` 使用 AES-CBC/PKCS7；实际封面响应为非图片密文 | 图片地址存在，但缺少解码参数 | F1：视频/图集的列表、详情及图集正文补齐本地 `X-Lume-Image-*` 参数，使用现有解码器 |
| E2：41封面正文为 Fernet token、`@@@`、剩余 Base64，token 明文为 data URI 前缀 | 单独解密 token 不足以还原整张图片 | F2：源声明 Fernet 编码；应用校验 token HMAC，解密并拼接剩余图片数据 |
| E3：41 `filters()` 限制10组/每组40项，`list()`未读取筛选值 | 点击筛选仍请求默认列表，分类被截断 | F3：读取并去重多组选择，传入 `tag` 参数；移除人为数量截断；升级缓存格式并设一小时有效期 |
| E4：127分类页面9项只通过图片 alt 提供名称；裸列表接口默认返回一批失效IP图床条目 | 9项分类被丢弃，默认列表封面失效 | F4：补读 alt，加入四维筛选；默认排序匹配站点人气列表，保留最新排序选项 |
| E5：91站内包含带连字符的 `sports-live` 分类，旧正则不匹配 | 部分分类缺失 | F5：支持连字符、下划线、完整/相对链接及嵌套标题；移除站点没有提供的独立排序筛选 |
| E6：自动方向在宽高未知时默认横屏，随后由 stats 改为竖屏 | 短剧先横后竖闪动 | F6：详情页预启动内核静默装载实际媒体并读取尺寸，移交同一个实例；播放页不重复装载；未知尺寸保持竖屏，强制方向偏好仍优先 |

三个站点的真实图标均已声明并验证返回有效图片；91图标为ICO，127使用移动主题ICO，41使用公开站点配置的站标（扩展名jpg，真实内容PNG）。
