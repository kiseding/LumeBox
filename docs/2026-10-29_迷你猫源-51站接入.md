# 迷你猫源（hmtv 51 站）接入 · 2026-10-29

## 是什么
xiaosag/hmtv 不是网站，是一个**源聚合服务端**：
ode index.js 后监听 8888，把 51 个内置站点（网盘 4K、短剧、ASMR、听书、极速影院…）统一暴露成 HTTP 接口：

| 接口 | 说明 |
|---|---|
| GET /config | TVBox 配置（含 51 个站点的 key/name/api） |
| POST /spider/<key>/3/home | {class:[{type_id,type_name}], filters, list} |
| POST /spider/<key>/3/category | body {id, page, extend} → {list, page, pagecount} |
| POST /spider/<key>/3/detail | body {id} → {list:[{vod_*, vod_play_url,…}]} |
| POST /spider/<key>/3/search | body {wd, page} → {list} |
| POST /spider/<key>/3/play | body {id, flag} → {parse, url, header}（已处理签名/防盗链/网盘解析） |

## 源怎么做的
sources/video/hmtv.js（id hmtv_video，v2 协议）：

- categories()：把构建时抓下来的 **47 个站点 × 347 个分类**拍平成 站点|分类 的 id，标题 站点名·分类名；
- list()：/category（或 /search）；home() 用数据最全的「茶杯狐」首页；
- detail() / chapters()：/detail 拿 od_play_url，按 \$\$\$ 拆线路、# 拆集数，也带回线路名；
- content()：先 POST /play {id, flag} 换出真实 m3u8/mp4（连同 header），换不出来才退回网页播放；
- 封面：服务端把图转成 http://127.0.0.1:8888/img?u=…，源里统一改写成当前站点地址。

v2 字段：settingsApiVersion: 2、endpoints.site（本机 + 局域网两行，App 里可切）、commonSettings（pageSize/playbackMode）、settings（说明 + 「刷新分类」动作，回 settingsAction）。

## 用法
1. 任意常开机器（PC/NAS/VPS）跑：
ode index.js（需同目录 index.config.js），默认 8888；
2. App 里本源「站点地址」填那台机器：http://IP:8888；
3. 站点自己改了分类，用源设置里的「刷新分类」重抓（写 sites.json 缓存）。
