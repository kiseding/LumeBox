# AI 图片功能说明

## 超分模型无需手动安装

App 内含漫画、照片两类 waifu2x 模型，各有 0–3 级降噪，共 8 个。iOS 首次使用超分时，在后台编译当前需要的模型并缓存。重新安装 App、清理缓存后，下次使用仍会自动准备，无需点安装，也不需要联网下载。

不会在 App 启动时一次编译全部模型。首次使用可能较慢，后续复用缓存；内存中最多保留两个最近使用的模型，避免漫画和海报交替出现时反复加载。原始模型优先使用本地导入版本，否则读取 App 随包资源。编译缓存损坏时自动重建一次。

「模型高级管理」里的准备、重新安装、导入和清理用于排查问题，日常不用操作。设备端超分目前仅支持 iOS；Android 模拟器可预览设置布局，不能验证 Core ML 效果。

## 三种功能同时使用

| 功能 | 何时运行 | 资源控制 |
| --- | --- | --- |
| 自适应颜色 | 页面需要封面配色时 | 首页取色只解码至最大 64 像素；颜色有缓存，不为取色额外触发超分 |
| AI 超分 | 开启自动超分且图片属于选中范围，或手动点击超分 | 阅读页、封面、海报和手动超分共享并发预算，默认 1；自动队列最多 32 个，失败时回到原图 |
| AI 上色 | 手动点击「AI 上色当前图片」 | 保存配置不会自动上传图片；离开处理页会取消本页持有的请求 |

三者没有互相调用的处理循环。超分将宽、高各放大 2 倍，输出像素变为 4 倍，因此开启大量封面和海报超分仍可能增加等待、内存、耗电和发热。并发默认 1；不要把「没有功能冲突」理解成没有性能开销。超大图片保留原图，下载文件不会被覆盖。

本次验证覆盖并发、退出取消、取色绕过增强、接口格式和窄屏布局。没有把 Android 模拟器表现当成 iPhone 的 Core ML 帧率或温度测试。

## 如何确认当前图片已超分

- 漫画详情：点击「图片信息 / 超分状态」。
- 视频详情：右上角「更多」→「图片信息 / 超分状态」，会区分源站海报和当前显示的 TMDB 海报。
- 手动处理：完成后显示处理状态和原始/输出尺寸，并可以切回原图对照。

例如「已完成 AI 超分 · 500×750 → 1000×1500」表示设备执行了 2 倍超分；「无需超分」会说明宽度阈值；处理失败会说明已保留原图。状态来自实际处理请求，按图片分别记录，不拿另一个任务的结果冒充当前图片。缓存图可能保留此前的处理状态，重新加载后更新。

TMDB 匹配、简介、年份、评分和剧集数不经过超分。TMDB 海报现在也接入图片处理，但使用独立图片管线，保留 TMDB 的图片地址及代理配置，不携带源站 Cookie。取色共用原始图片字节缓存，不为取色重复超分。原图宽度已达到阈值时会跳过，开启开关不表示每张图片都要放大。

## AI 上色怎么填

上色需要能接收原图并返回修改后图片的**图片编辑服务**。DeepSeek 官方接口不能输出上色图片，其地址和文字模型不能填在这里；它可以继续用于 AI 翻译。

使用支持 GPT Image 的 OpenAI API 账号时，可按以下示例填写：

| 字段 | 填写示例 |
| --- | --- |
| 图片编辑接口 | `https://api.openai.com/v1/images/edits` |
| 上色模型 | `gpt-image-1-mini`（需要账号具有该模型调用权限） |
| 上色提示词 | 保留页面默认内容即可 |
| 上色 API Key | 图片编辑服务自己的 API 密钥 |

点击「保存上色配置」，再到图片工具点击「AI 上色当前图片」。文字对话接口 `/chat/completions` 不能代替图片编辑接口。

上色密钥单独保存在 iOS 钥匙串，不会改动 AI 翻译密钥；Seedream 与通用上色分别保存密钥。为兼容旧配置，通用上色尚未单独保存密钥时沿用原来的翻译密钥；Seedream 必须填写火山方舟的密钥。页面留空只保留已有密钥。

当前支持通用 multipart 图片编辑和 Seedream JSON 图生图，两者都读取 `data[0].b64_json`。GPT Image 请求省略旧的 `response_format` 参数，使用 PNG 输出；其他兼容图片编辑接口仍请求 `b64_json`。Gemini 原生 API 尚未适配。

## 国内上色预设

在「上色服务」选择「火山方舟 · Seedream（国内）」，会自动填写：

- 接口：`https://ark.cn-beijing.volces.com/api/v3/images/generations`
- 模型：`doubao-seedream-5-0-flash-260915`
- 输出：2K、单张图片，保留 AI 水印。

在火山方舟开通该模型的 API 调用权限，创建 API Key，复制到 App 的「上色 API Key」，保存即可。不要填 DeepSeek 密钥，也不要填网页会员密码。此过程需要用户自己登录服务商账户；App 不代为开户或充值。

2026-10-28 核对的官方参考输出价：Seedream 5.0 Flash 为 ¥0.12/张，Seedream 4.0 为 ¥0.20/张；按 Flash 标价生成 100 张约 ¥12，以账户实际价格和账单为准。若账号只开通了 4.0，可把模型改为 `doubao-seedream-4-0-250828`，App 同样适配。不能凭价格保证漫画上色效果，先试一页。

参考：[官方价格](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh)、[Seedream 5.0 Flash 能力与模型 ID](https://docs.volcengine.com/docs/ark/seedream-5-0-pro?lang=en)、[图片 API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh)。

## 源图标怎么使用

源设置 → 图标与外观 → 一键获取站点图标 → 保存。无需自己到网站查图片地址。

主动获取会比较源声明、Apple Touch、网页图标、Web App manifest 图标和常见 favicon 路径，按实际短边像素选取更清晰的版本，不只相信网页声明的尺寸。候选数、单次请求大小和并发受限；大图解码检查在后台进行。高清结果写入现有图标缓存，源列表正常打开时复用缓存，不逐卡扫描整站。找不到高清候选时保留可用小图，完全失败则保留原自定义设置。

「自定义源图标」只是手动替换图片的可选功能，不会使用时留空即可。列表仍按 33×33 显示，获取更高清的原图不会改变卡片尺寸。

图片编辑模型也可能改变细节、字形或构图。先用一页确认保留线稿和文字的效果，再决定是否继续使用。接入格式用模拟响应验证，未使用用户真实密钥进行付费上色测试。

官方资料（核对于 2026-10-28）：[OpenAI 图片编辑 API](https://developers.openai.com/api/reference/resources/images/methods/edit)、[GPT Image Mini](https://developers.openai.com/api/docs/models/gpt-image-1-mini)、[DeepSeek 模型输出类型](https://api-docs.deepseek.com/api/list-models/)。
