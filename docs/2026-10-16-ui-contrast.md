# 全局UI可读性调整

仅调整样式，不调整页面顺序、网格列数、间距、组件结构或功能。

- 全局字号增加1pt，显式字体最低600字重。阅读器正文测量与绘制共用同一更新样式，页眉页脚同步增加字号。
- 亮色：深色不透明文字、灰蓝页面底、白色卡片和浅蓝灰内嵌模块。
- 暗色：浅色不透明文字、深色页面底、独立蓝灰卡片和更亮的内嵌模块。
- 猫源站点、常规源选择弹窗的排列和网格均提供独立底色、轻阴影。
- 小字、占位文字、选中标签、禁用按钮及11种主题色均检查至少4.5:1文字对比度。
- 毛玻璃开关不变。透明度仅在绘制时映射为86%至100%的稳定底色，保存值、滑杆与模糊强度不变；透明度调节保持连续有效。
- 包含单元测试及320/390宽亮暗源选择器截图检查。预览中的Windows字体只在测试中加载，不影响iOS系统字体。

iOS实际毛玻璃、系统分享、画中画与模型加载效果仍需真机验收。
