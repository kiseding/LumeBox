# 新增图源：XAnimu（xanimu.one / xanimu.art，2026-10-13）

用户给的地址是 https://xanimu.one/zh-CN/ ；本源脚本 `video/xanimu_video.js`（id `xanimu_video`，名 **XAnimu**），
已进源仓库视频订阅清单；App 里重贴一次视频板块订阅即可导入。

## 站点与域名（实测）

| 域名 | 本机直连 | 说明 |
|---|---|---|
| `xanimu.art` | ✅ 可用 | **首选**；与 .one 是同一个 WordPress 站（同主题、同 `/zh-CN/` 路径、同 `?p={id}` 跳转、同 CDN） |
| `xanimu.one` | ❌ 连接被重置 | 用户给的域名；需代理 |
| `xanimu.com` | ❌ 连接被重置 | 备选 |

脚本按「`.art` → `.one` → `.com`」试并**记住可用的那个**（存在沙盒存储里）；
连接类失败（域名被重置 / DNS）不会被当成站点错误，直接换下一个域；
三个域全连不上时如实报网络错误并提示在「图源 → 网络配置」里配代理。

## 抓取口径（每条都对着实时页面核过，快照见源仓库 `snapshots/xanimu_*.html`）

- **列表 / 分类**：首页 `/zh-CN/`、分类页 `/zh-CN/{分类路径}/`，翻页 `/page/{N}/`；
  分页器里有 `a.next.page-link` 才有下一页（**末页那条整个不出现**，快照实测）。
- **排序开关**：站点自己的四个 tab 是 `?filter=latest|most-viewed|longest`（不带 = 受欢迎），
  首页与分类页都吃这个参数；脚本把它们做成 `filters()` 的一个「排序」组，`list()` 读 `filters.sort`。
- **条目**：`<div class="video-block" data-post-id="{数字id}">`；封面**首张是 `src`、其余是懒加载 `data-src`**
  （只认一种会少 46/47 张封面）；同一张卡里还有个分类角标 `img.vid-tag-info-tool`，不是封面，只认 `img.video-img`。
- **搜索**：`?s={词}`，翻页 `/zh-CN/page/{N}/?s={词}`。中文关键词命中率差（实测「触手」1 条、「3d」500 条）
  ——这是站点自己的搜索行为，脚本如实透传，不替它凑结果。
- **详情**：`?p={数字id}`（301 到 `/zh-CN/{id}-{slug}/`）——所以 **id 就存数字**，不用解析中文 slug。
  标题 `<h1>`、简介 `div.video-description`、分类 `a.label-cat-video`、标签 `a.label-tag-video`、
  时长/发布日期来自 JSON-LD 的 VideoObject。
- **播放**：`<source src="…_high.mp4?verify=…" title="high">` 与 `…_low.mp4` 两条 mp4 直链
  （nosofiles CDN，令牌由站点在页面里现生成，实测不带 Referer 也能拉 206）。
  清晰度走 `content.qualities`（高清/标清），默认取站点自己排在前面的 high。
  页内播放器 JS 还有一条极少数视频才用的 `var toFetch="…"` → 拉 JSON 取 `videoHLS`，
  脚本按这个形状兜底（本轮样本里 toFetch 全是 false，未实测到真例，代码注释已说明）。
- **一条视频 = 一个条目**（站点没有分集）：`chapters()` 给一条「正片」，不再多发一次请求。
