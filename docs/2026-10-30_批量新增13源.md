## 各站的关键坑（写源时验证过）

- **404xav**：`var play_data` 是 base64 包着 zlib raw-deflate 的 JSON，沙箱要自己写 inflate，成本高，本批未做。
- **KVS 系（cartoonporn）**：`/get_file/...` 会 302 到 CDN，必须跟随；`/vids/<id>/x/` 会 301 到规范 slug。
- **pmvtube**：CDN 开了防盗链，**带 Referer 反而 403**，播放请求必须不带 Referer；`verify=` 签名会过期，每次播放现取。
- **avbebe**：`data-item` 是 HTML 实体编码的 JSON，unescape 后再解析；播放必须带 `Referer: https://avbebe.com/`。
- **91pinse**：`POST /api/videos/<id>/playback` 只认 `Origin: https://91pinse.com`，缺了 403；个别视频详情页本身 500，要按「详情不可用」降级而不是整源报错。
- **hstream**：`POST /player/api` 要 `X-CSRF-TOKEN`（来自页面 `data-csrf`，不是 meta）+ 会话 cookie；`stream_domains[]` 自带 `https://`，拼接前要剥协议。
- **gifscroll**：列表页 HTML 是空壳，数据走 `/backend.php`；embed 页里 m3u8 的斜杠是转义的，先去掉反斜杠再匹配。
- **xxxfollow / 小黄鸟 / ogfap**：卡片不在 HTML 里（SSR JSON / 纯 API）。小黄鸟与 ogfap 没有可用的「按 id 取单条」接口，列表阶段把 id→媒体地址写进 `LumeSource.fs` 缓存，`content()` 先查缓存。
