# 新增美图源：栖影图库（qiying-media-vault.cfmxy123.workers.dev）

2026-10-27 · 漫画板块 /「美图」分组 · `sources/photo/qiying.js`

## 1. 站点是什么

`https://qiying-media-vault.cfmxy123.workers.dev/` 是「栖影」：**Cloudflare Worker 上的一套纯静态站**
（`index.html` + `app.js` + `media-data/`），没有后端接口——数据是预生成好的 JSON 分片，前端自己拉下来
在浏览器里做分类、标签、搜索、分页。所以做源也只能照它的数据形状来，不能像别的站那样找 `/api/xxx`。

统计：21707 条帖子、50459 张图片、10031 段视频；其中 18825 条带图片（12167 条纯图片、6658 条图文），
2877 条只有视频；18985 条没有标题（抓取时源站 404）。

## 2. 数据地图（`media-data/v2/`，每份都有同名 `.gz`）

| 文件 | 内容 |

| `manifest.json` | `schema=2`；`catalog.files`（28 个分片 × 800 条）、`details.buckets=96`、`modes.images/videos` |
| `catalog/catalog-NNN.json` | 目录，按时间倒序。记录 `{p:pid, t:标题, d:简介, r:封面路径, i:图片数, v:视频数, k:[分类], g:[标签], a:作者, c:创建时间}` |
| `details/details-NNN.json` | 明细，**桶号 = pid % 96**（三位补零）。记录 `{p:pid, i:[{i,p,w,h,c}], v:[…]}`，图片在 `i[].p` |

视频签名算法（`app.js` 里 `signVideoClient`）是
`auth_key = 秒级时间戳-rand-0-md5("<路径>-<时间戳>-<rand>-0-RnOxyCIc5eDPFpJY")`，`rand = md5(路径+时间戳)` 前 13 位。
算法还原出来了、但两条 CDN 都取不到流，所以**本源只做图片**：`i=0` 的纯视频帖不进列表，
图文帖在选集标题里标一句「另有 N 段视频」。

## 4. 网络前提：国内要代理

`*.workers.dev` 在国内被 DNS 污染。本机实测：

- `Resolve-DnsName qiying-media-vault.cfmxy123.workers.dev` → `69.171.247.71`（Facebook 的地址，明显是被投毒）；
- 走 DoH 查真值 → `172.67.217.239` / `104.21.70.20`（Cloudflare）；
- `op.vkjyoi.cn` 本地解析成 `127.0.0.1`。

所以：源在「源设置 → 网络 → 代理」里配上代理才能用（`node tools/lume-source-check.mjs` 跑测时用
`NODE_USE_ENV_PROXY=1` + `HTTPS_PROXY`）。

## 5. 脚本怎么实现

- **索引**：28 个目录分片（三片一批，正好贴住宿主单域名并发上限 3）压成紧凑记录
  `[pid, 标题, 封面, 图片数, 视频数, 分类, 作者, 创建时间, 简介(180 字), 标签]`，
  落 `LumeSource.fs` 的 `index.json`（约 2.6 MB / 18825 条，解析 ~5 ms），有效期 6 小时；
- **gzip**：沙箱没有 `DecompressionStream`/`pako`，`.gz` 一律用宿主原生
  `LumeSource.tools.inflate`（28 片一共 ~400 KB，比明文 13 MB 省一个数量级）；
  宿主不给 `bodyBase64` 或 inflate 抛错时立刻置位 `gzUnsupported`，整轮回落明文 `.json`
  （Node 侧的 `tools/lume-source-check.mjs` 就是走这条回落路径）；
- `categories()`：全部（1.9万）+ 19 个分类（带条数）+ 未命名；
- `home()`：最新收录 12 + 今日吃瓜 / 师生专栏 / 深夜撸片 各 12；
- `filters()`：分类 / 内容（全部·仅图片·图片+视频）/ 排序（最新·图片最多）；
- `list()`：索引内存过滤（分类、关键词多词 AND 匹配标题/标签/作者、内容类型），分页 20；
- `detail()`：索引里直接给标题/封面/分类/作者/简介/标签；
- `chapters()`：一个章节「全部 N 张图片（另有 M 段视频）」；
- `content()`：按 `pid % 96` 取明细桶 → 图片路径 → 按选中的图片域拼绝对地址，返回 `{kind:'images'}`；
  抓取脏数据（`/upload_01/upload" alt="xx.jpg`、`/upload/u![Screenshot…`）会先按分隔符截断，
  混进路径的域名（`/new.tuzhoo.cn/...`）会还原成 `https://`。

## 7. 限制

- 站点是静态数据，索引整轮 28 个分片：**第一次打开约 1–3 秒**（之后 6 小时内走 fs 缓存）。
  拉不动会给可读错误（多半是没配代理 / Cloudflare 拦截 → `NEED_WEBVIEW_VERIFY`）。
- 视频不可播（见第 3 节），本源不提供视频内容。
- 站点数据是抓取来的，脏路径/重复条目会有（不影响主流程，脚本按分隔符截断）。
- 内容按 18+ 分级（`SourceContentRating`：`qiying_vault` / 「栖影图库」）。
