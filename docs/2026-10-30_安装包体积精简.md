# 安装包体积精简（2026-10-30）

## 结论

未签名 IPA 从 **318.5 MB**（1.0.171，`docs/2026-10-19_前期交流功能进度与待办.md`）
降到 **约 50 MB**。原因只有一个：四个随包模型占 268 MB，而它们服务的都是可选功能。

## 之前为什么大

| 内容 | 体积 | 位置 |
| --- | --- | --- |
| 离线音色包 vits_aishell3（5 个 bz2 分片） | 140.1 MB | `assets/speech/vits_aishell3/pack.*` |
| MobileCLIP-S0（zip） | 94.7 MB | `assets/models/intro/mobileclip_s0.zip` |
| YAMNet | 15.3 MB | `assets/models/intro/yamnet.tflite` |
| waifu2x × 8 | 16.9 MB | `assets/models/waifu2x/*.mlmodel` |

`pubspec.yaml` 用目录声明资产，目录里有什么就无条件进包；这三个功能本身都要求
用户手动点一次「准备／安装」，资源却始终随包发布。早期 IPA 只有 20.5 MB
（`deferred-todo.md`，run `37639834875`），这两批模型是 10-16、10-18 两次提交带进来的。

## 这次改了什么

**一、模型不再随包发布，改为首次使用时下载**

`lib/core/models/model_source.dart` 是唯一的取用口径，顺序是「测试注入 → 随包资产 →
下载」：

- 包里只留清单：`manifest.json`（音色包分片表）、`checksums.json`、`ORIGIN.json`、
  `prompts.json` 与各许可文件，合计约 0.1 MB。
- 权重首次使用时下载，落盘位置与原来「安装内置模型」完全一致（Application Support），
  下游解压、编译、加载路径一行未改。
- 每份都校验 SHA-256（与仓库清单同源，钉在代码里）；校验不过删除临时文件并报错，
  不会把半个模型交给原生层。
- 下载是流式的（最大一份 95 MB），不整块进内存；拼音色包时逐片下载、拼完即删，
  峰值磁盘只多一个分片。
- 三个入口文案改为如实说明（「首次会联网下载约 17 MB」「下载并启用离线音色包」）。

**二、纯浪费（不涉及功能）**

- 图标从 1024 px 降到 256 px：3.29 MB → 0.22 MB。设置页里图标只有 70 pt 见方；
  1024 母图移到 `tool/icon/`，只给 `flutter_launcher_icons` 生成 iOS 图标时用。
- 内置弹幕脚本 `upstream.cjs` 以 gzip 存放：3.15 MB → 0.78 MB。解压后字节完全一致，
  `manifest.json` 的 `patchedSha256` 与安装期校验都不用改。
- `assets/reference/`（0.24 MB）移出资产列表：运行时不读，只给版式对照脚本用。

## 下载来源

默认走本仓库的 Git 数据（GitHub contents API 的 raw 形式，单文件到 100 MB 仍可直传）：

```
https://api.github.com/repos/kiseding/LumeBox/contents/<asset 路径>
```

换成自己的对象存储只要构建时覆盖，目录结构与仓库一致即可：

```bash
flutter build ipa --dart-define=LUME_MODEL_BASE=https://your.host/lumebox/
```

> 真机在国内网络从 GitHub 拉 250 MB 会很慢。若长期使用，建议把
> `assets/models/**`、`assets/speech/**` 同步到国内可访问的存储，再用上面的
> `dart-define` 指过去；代码不需要改。

  要求的 3.13.4，无法本地 `flutter analyze`／`flutter test`，以 CI 为准）。
- 单测适配：`ModelSource.debugReader` 让测试直接从仓库读权重，不联网。
  `test/comic_image_tools_test.dart` 的「八个模型随包」用例改为「不随包但可从仓库取到」。
- **待真机确认**：首次启用离线朗读／片头识别／waifu2x 时的下载耗时与失败提示；
  断网时应给出「下载失败……也可改用「从文件安装」」而不是一直转圈。
