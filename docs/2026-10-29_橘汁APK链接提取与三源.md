### 2.3 App 自有后端（重要发现）

`https://juziapp.hzhcbkj.cn`（APK 里 `ServerErrorActivity` 的兜底地址 + 运行时域名）：

- `GET /v3/api-docs` **完全开放**（OpenAPI 3.1，273 条路由，`Swagger UI` 也在 `/swagger-ui/index.html`）；
- 开放 JSON 端点（无签名可用）：
  - `/api/v3/drama/treeCategory` —— 分类树（电影/剧集/综艺/动漫/短剧…）
  - `/api/v3/debug/drama/list?page=&pagesize=&typeId=` —— 列表（含 `videos[].path/source`）
  - `/api/v3/ranking/list` —— 排行榜分组
  - `/api/ex/v3/videoParse/test/videoUsableUrl?vodPlayFrom=&playUrl=` —— **换真播放地址**（实测返回 m3u8）
- 需「公共参数」签名头的端点（无头时 `code 500 公共参数请求头不能为空`）：
  `/api/proto/v5/*`（含 `getDetail`）、`/api/ex/v3/security/*`。
  后果：`videos` 只给每部作品**第 1 集**，长剧后续集要签名才能取。

## 三、没能做成源的站点（附原因）

| 站点 | 结论 |
|---|---|
| 种子猫 `zhongzimao.com` | 域名已停放（302 → `getapp.netguardprotect.com` 广告页） |
| 磁力猫 `cilimao.cc` | 域名停放（ParkLogic 停放页） |
| `2.cilimm.com`、`zhainanbt.co` | DNS 不解析 |
| BT猫 `bteat.com`、BTStation、Monova | 直连与代理均不可用（502 / TLS 握手失败 / 超时） |
| 点播 `hqvod.com` | **已做成 `webplayer` 源**：`api.php/provide/vod/` 返回 `closed`，但 `/index.php/ajax/data?mid=1&tid=&page=` 是开的（13.4 万条、10 条/页）；详情页可读；播放页 `/bofang/*` 挂滑块人机校验（`/huadong_*.js`），脚本一律 403，且连续请求会短时封 IP（实测连抓 5 页后整站 403，数分钟恢复） |
| 天天 4K（`dyttandroid04-…cos.ap-shanghai.myqcloud.com`） | 只有对象存储桶：`?list-type=2` 返回 `AccessDenied`，`/index.m3u8`、`/video/`、`/4k/` 全 404，清单也没给可用接口域名 ⇒ 无法枚举内容，不做源 |
| YouTube（`i.ytimg.com`） | `i.ytimg.com` 只是封面域；要播得走 innertube 接口 + `signatureCipher` 的 JS 签名解密（`n`/`sig` 变换随播放器版本变），纯 JS 源内不现实，且需要代理 ⇒ 不做源 |
| 电影天堂 `dy2018.com` | 302 → `dytt8899.com`，只有磁力/迅雷链接（无 m3u8），LumeBox 无磁力播放形态 ⇒ 不做源 |

磁力站群只提供种子/磁力，LumeBox 视频源没有「磁力播放」形态，所以这一半链接只做记录、不成源。
