# 网页播放器按钮选集

源的 `content` 可返回 `kind: "webplayer"`、HTTP(S) `pageUrl` 和 `webPlayerOptions.episodeSelector`。App 通过 `LumeSource.web.episodeSelection === true` 声明支持，旧 App 不应忽略集数后播放默认集。

App 在页面加载完成后查找一个可见、启用且 `type="button"` 的按钮，仅在请求页面的同源同路径执行。选择器按 JSON 字符串传入，不作为脚本拼接执行。等待最长 60 次、每次间隔一秒；超时显示重试入口。刷新重新选择，导航或关闭取消旧轮询，进入后台暂停媒体并取消选集，回到前台不自动播放。

注视影视源使用默认线路 `#play-source-panel-g1`。原生列表和集数选择后进入网站播放器，视频的 blob 地址保留在页面内部。此模式沿用网页播放已有边界：无原生弹幕、手势、画中画、字幕样式和播放进度记忆。人工验证仍由用户在网页完成；桌面浏览器验证状态不复制到手机。

验证：Flutter 页面、真实 QuickJS 桥接、Kazumi 和播放入口测试通过；选择器脚本另验证了同路径、唯一可见按钮、表单按钮拒绝和字符串注入隔离。源站浏览器实测确认默认选集和第 2 集实际加载；尚未进行 iPhone 安装后的完整端到端测试。
