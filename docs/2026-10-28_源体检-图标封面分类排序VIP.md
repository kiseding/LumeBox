## 二、这轮动过的东西

1. **站点图标**：11 个源补 `"icon"`，取值逐个 curl 过（favicon.ico / .png / .svg / 站点 logo）。天撸啦与 ReddXXX 站点本身没有可取图标（404 / CF 403），保持无图标。
2. **封面**
   - KKAV：列表 `smallpic` 指向 `sq.2277ww.com`，该域已 ECONNRESET；同路径换到配置里的图片域 `https://fengmian.gszy12348.com/data/`（实测 200 image/jpeg）。
   - 海角情：正文里没有 `<img>` 的文章原来 cover 为空，列表请求加 `_embed=wp:featuredmedia`，没有正文图就用特色图（实测原来空的三条现在都有 `img.haijiaoluv.top` 的 webp）。
3. **分类 / 筛选 / 排序**
   - 在线影院：导航里「更多分类」「全部」指向首页的伪分类不再进分类表。
   - KKAV：`categories()` 与 `filters()` 给的是同一批分类，界面会出现两条一样的行 → 删掉 `filters()`。
   - 海角情：新增「排序」组（最新 / 最热 = WordPress `orderby=date|comment_count`），分类组去重。
4. **VIP**
   - 91热爆「VIP专享」：`delivery.douyinpaly.com/hls/contents/videos/…/index.m3u8` → 200 `#EXTM3U`。
   - 天撸啦「private」：`m2.kdamao.com/hls/contents/videos/…/index.m3u8` → 200 `#EXTM3U`。
   两者都不需要账号，源里直接给直链。
5. **CDN 边缘缓存的两个坑**：`video/KKAV.js` 与 `video/海角情.js` 在 jsDelivr 的 fastly/gcore/cdn 上长期停在旧版本（purge 多次也不翻），
   改成新文件名（`KKAV-2.js`、`海角情-2.js`，源内 `name` 不变）后三个 POP 立刻回源。订阅列表与 catalog 已自动跟随。
