# 离线资源精简与网页整剧传递

## 离线资源

语音运行参数、音色、ONNX 权重、词典和四个 FST 均保持不变。`prepare_speech_assets.py` 从原始分片校验并重打包 manifest 中的七个运行文件，省去未使用的 FAR 与第二份量化模型，内置压缩包从 140.12 MiB 降到 110.43 MiB。安装时仍逐文件校验原 SHA-256；手动导入原始官方压缩包继续支持。已有安装可继续使用。

片头识别将八条固定提示文本的模型输出预计算为 anchor_vectors.json，省去约 74.6 MiB 的文本编码器压缩权重。保留原图像编码器与 YAMNet，全部功能离线运行。新安装只编译图像模型，旧内置文本模型在升级安装图像资源成功后清理；自定义完整模型对和专用分类器继续支持。

干净构建先运行：

```text
python tool/prepare_intro_models.py
python tool/prepare_speech_assets.py
```

运行资源 ZIP、语音分片和派生校验清单由脚本生成，不提交 Git；固定向量与原输入清单提交。`check_quality.ps1` 和 iOS 工作流自动准备资源。`python tool/test_compact_assets.py` 检查打包字节一致、排除无用文件、损坏拒绝及确定性重建。语音实际解包由 speech_local_model_test 验证。

## 网页选集

过去 fm.vodInline 只传当前解析地址，原生 DirectVideoSource 只能显示一集“正片”。现在保存当前网页会话的完整剧集目录、选中集数和解析函数，详情与播放器使用同一个临时 DataSource。首播复用已解析地址，切集和重试再请求原网页解析，不提前批量解析失效链接。剧集请求头随解析结果传递，网页关闭或解析失败会结束等待。

只调用 fm.play 的单条媒体保持原行为。网页实际提供了多少剧集，就显示多少；未提供的其他线路不会虚构。回归覆盖 47 集、非首集选择、逐集解析、请求头、无效下标、解析异常和会话关闭。

## 订阅分类兼容

源声明 `photo`／美图按漫画板块导入，`audiobook`／有声小说按视频板块导入，数据库与缓存仍使用现有 Section。映射后继续校验目标板块；美图不能导入视频，有声不能导入漫画。此前此类源会使对应订阅“不完整同步，已保留旧源”，从而阻止清理已下架项目。修复后完整同步可继续正常移除旧源。

本次下载核对发现 jsDelivr 上旧 `subscriptions/video.txt` 曾保留下架前内容，当前 `subscriptions/cdn/video.txt` 与带哈希清单均已更新。App 将官方 CDN 的旧清单地址迁到 CDN 专用目录，GitHub 清单网络失败后的回退也使用该目录，避免再次引用旧 raw 清单缓存。自定义仓库和带查询/片段的 URL 不改写。

总订阅中的 CDN 哈希地址是缓存快照，不能作为永不变更的订阅根保存。旧快照记录加载时迁成逻辑分类地址，并合并成员与用户排除项；每次实际同步先读取当前 CDN 总订阅，再下载其指定的最新快照。漫画/视频汇总地址按当前总订阅对应板块展开。当前指针获取失败会保留旧源并报告失败，不使用可能过期的清单进行增删。
