## 1. 播放器偏好接线

### 1.1 浏览器 UA

- 新增 `lib/features/video/playback_preference_wiring.dart`：
  - `withUserAgent` / `applyUserAgent`：用户填写 UA 且媒体没有自带 `User-Agent` 时补上；
  - 片源或网页验证会话自带的 UA **优先保留**，与设置页说明一致。
- 生效位置：`VideoPlayerPage._loadMedia`，所有起播/换线路/换集最终都走这里；播放请求头（`_playbackRequestHeaders`）同步带上该 UA。
- 网页主页的 WebView 也读取同一个 UA（`WebHomePage`）。

### 1.2 字幕语言

- `PlaybackPreferenceWiring.chooseSubtitleTrack` 负责把设置映射到字幕轨：
  - `跟随片源`：不干预；`关闭字幕`：选空轨并同步关闭字幕开关；
  - 简体中文、繁体中文、粤语、英语、日语、韩语：优先匹配轨道 `language` 字段，再匹配标题关键词；
  - 短语言码按词边界匹配，避免把 “French” 里的 “en” 当成英语。
- 生效时机：每次加载新媒体后自动选一次；用户手动选字幕或加载外挂字幕后不再覆盖。
- 若内核暂未给出字幕轨，会自动重试几次，避免起播瞬间轨道列表为空导致设置失效。

### 1.3 详情页“只选中不播放”

- 设置开启后：
  - 视频详情页点选集只改变选中态并提示“点下方播放开始”；
  - 猫源详情页点选集同样只切换选中态，主播放按钮按当前选中集起播。
- 关闭时保持原来的“点选集直接播放”。

## 2. 网页主页源

- 存储：`lib/core/web/web_home_sources.dart`
  - 写入视频板块的 `video.web.homes.v1` 设置（JSON），不新增数据库表；
  - 支持新增、编辑、删除、排序；地址只接受绝对 `http(s)` URL。
- 选择器：
  - “网页”分类不再是“尚未接入”，会列出已保存的主页；
  - “添加视频源 → 网页主页”打开新增对话框（名称 + 地址，自动补 `https://`）；
  - 卡片右上角可编辑/删除；选中项显示“当前使用”。
- 打开与返回：
  - `WebHomePage` 用内置 `webview_flutter` 打开主页，支持页面内前进/后退、刷新、加载进度与错误提示；
  - 页面是压栈路由，系统返回/左上角返回先退网页历史，再回到视频页；
  - 记录最后使用的主页 id（`video.web.selected`），重启后选择器仍能标出“当前使用”；
  - 外部协议（如 intent/自定义 scheme）不直接执行，给出提示。

## 3. 猫源 parse=1 网页解析

- 契约：`CatDataSource.content` 遇到 `parse=1` 时抛 `CatWebParseRequired`（继承 `SourceException`，后台预加载/自动连播会安静降级，不会崩溃）。
- 解析页：`lib/features/cat/cat_web_parse_page.dart`
  - 用真实 WebView 打开解析页，注入脚本监听 `performance` 资源、`video/source` 元素、`fetch`/`XHR` 和 `play` 事件；
  - 只收集 http(s) 的 `m3u8/mp4/flv/mkv/m4v/webm/ts/mpd` 地址，去重后列出候选；
  - 用户点候选地址 → 返回播放器起播；解析页支持刷新和取消；
  - 候选地址会补上解析页的 `Referer`，提高防盗链成功率；
  - 若页面使用 blob/加密流或需要登录，可能取不到地址：此时保留原来的“换直连线路”提示，不做虚假成功。
- 直连回退：parse=1 解析失败/取消时，原有直连线路逻辑不变。

## 4. 手工验收建议（iPhone）

1. 播放器偏好：填 UA 后播放带防盗链的源；切换字幕语言观察是否自动选中；打开/关闭“只选中不播放”后点选集。
2. 网页主页：添加一个普通网站（如 https://example.com），从选择器打开，验证页面内返回/刷新/退出；编辑名称/地址后重新打开；删除后列表消失。
3. 猫源 parse=1：找一条 parse=1 线路播放，观察网页解析页是否识别到地址；点候选后能起播；取消后是否回到详情页且可换直连线。

## 5. 已知限制

- 网页解析依赖页面真实发出媒体请求：纯 blob、加密 HLS、需要登录/验证码的站点可能识别不到；
- WebView 的 Cookie 与播放器 HTTP 请求不是同一会话，个别站点可能需要直连或网页内播放；
- UA 只在片源没有自带 `User-Agent` 时生效；
- 字幕语言是启发式匹配，轨道命名很随意的源可能匹配不到；
- 以上均需 iPhone 真机确认，本机测试不代表真机行为。
