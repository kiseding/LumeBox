# 新增源：四色视频（www.d9y1w.top）

2026-10-29 · `sources/video/d9y1w.js`（`d9y1w_video`，视频板块，18+）

用户给的入口是 `https://www.d9y1w.top/index/home.html`。站点是「maomi」模板的成人站，
全站 HTML + 站点自己的两套加密，没有可直接吃的 JSON 列表接口（搜索除外）。

## 一、站点形状

| 用途 | 路径 |
|---|---|
| 首页 | `/index/home.html`（三个横滑板块：最新剧情 / 最新电影 / 最新精选） |
| 分类（全部） | `/{juqing|shipin|jingpin}/lists.html?page=N` |
| 分类（标签） | `/{juqing|shipin|jingpin}/list-<标签>.html?page=N` |
| 搜索 | `/search/{juqing|shipin|jingpin}-<关键词>-<页码>.html` → JSON 数组，10 条/页 |
| 详情 | `/{channel}/play-<id>.html`（只有标题与两条线路，**没有简介、没有封面**） |
| 播放 | 详情页内联 `var video = decodeString('<base64>')` + `m3u8_host/m3u8_host1 = decodeString(…)` |

三个视频频道之外还有 tupian（图集）/ meinv / xiaoshuo（小说）/ yousheng（有声）与一批赌博外链，
本源只做视频，其余全部过滤。

## 二、两套编码

1. `decodeString(x)`：base64 → UTF-8 明文（m3u8 路径、线路域名、菜单链接里的中文路径参数）。
2. `Decrypt(x, "883346")`：AES-256-CBC / PKCS7。key、iv 写在 `/assets/js/common/encrypt.js`：

   ```js
   const key = "SWRUSnEwSGtscHVJNm11OGlCJU9PQCF2ZF40SyZ1WFc="; // base64 → 32 字节 ASCII
   const iv  = "JDB2QGtySDdWMg==";                              // base64 → "$0v@krH7V2"（10 字节）
   new_iv = CryptoJS.enc.Utf8.parse(new_iv + suffix);            // suffix = "883346"（common.js）
   ```

   标题、分类名、菜单链接（`data-link`）、搜索结果的 `title`/`tags` 全是这套密文。

3. 卡片 href 是 `/cYc` + base64(明文路径) + `.html`（有的保留 `%3D%3D` 补齐，有的没有）。
   **明文路径本身可直接访问**（`/juqing/play-438649.html`、`/juqing/list-麻豆传媒.html` 都 200），
   所以源里只解不拼：先 base64 还原，再按明文路径取页。

沙箱没有 `atob` / `Buffer` / `crypto`，源内自带纯 JS base64 与 AES-256-CBC 解密
（S 盒写死，密钥表按 key 缓存，一页 20 条标题 ≈ 60 个分组解密）。

## 三、封面

卡片封面是 `data-base64="/videos/…/poster2.jpg"`，站点自己经
`fetchBase64Img(…, 'https://base4s.0827.la/')` 取回一段 `data:image/jpg;base64,…` **文本**。
App 的图片管线只吃图片字节，不吃文本 body；但**同一路径在媒体 CDN 上是真 JPEG**：

```
GET https://www.0734.la/videos/202610/26/6ade587ace6d9f989852cc86/poster2.jpg → 200 image/jpeg 143518
GET https://base4s.0827.la/videos/202610/26/6ade587ace6d9f989852cc86/poster2.jpg → 200 text/plain data:image/jpg;base64,…
```

所以封面用 `m3u8_host`（媒体 CDN）拼，域名从 play 页现取并缓存 6 小时，站点换 CDN 时封面自动跟着换。
抽样 10 张（poster/poster2/`/sis/ss/fmtu/*`）全部 200 `image/jpeg`。

## 四、播放

```
play 页 → var video = decodeString('<base64>')       → /videos/202610/25/<组>/<hash>/index.m3u8
        → m3u8_host  = decodeString('<base64>')      → https://www.0734.la
        → m3u8_host1 = decodeString('<base64>')      → https://s5.sanheyiliao.xyz（已 NXDOMAIN）

GET https://www.0734.la/<video>
→ 200 application/vnd.apple.mpegurl 79 KB
   #EXT-X-KEY:METHOD=AES-128,URI="/videos/…/ts.key"（同域，16 字节，200）
   分片在 s4.dt188.site，200 video/mp2t（852 KB / 段）
```

不需要 Referer、不需要 Cookie、没有 VIP 限制。`content()` 线路一直接返回，
线路二（备用域）先探一次，探不通就回落到线路一。

## 五、验证

```
node tools/lume-source-check.mjs sources/video/d9y1w.js
```

全绿：

- `home` 3 块（最新剧情/电影/精选，各 10 条）；
- `categories` 27 项（三个「全部」+ 菜单里 24 个视频标签，实时抓、30 分钟缓存）；
- `list` 20 条/页，`--category` 逐个验过（`juqing:`/`juqing:麻豆传媒`/`shipin:`/`jingpin:`/`jingpin:onlyfans`
  首条 id 各不相同），`--page 2` 换页正常；
- 搜索 `--keyword 麻豆` 30 条（三频道合并，每频道 10 条）；
- `detail` 标题与封面来自列表缓存（详情页本身无封面）、`chapters` 2 条线路；
- `content` 给 `www.0734.la` 的 m3u8，探活 `200 + #EXTM3U`（79 KB）。

## 六、限制

- 详情页没有简介/封面，`detail()` 的封面取自列表缓存（从别的入口直接跳到详情时是空封面）；
- 「最新」板块与列表只到站点自己给的分页为止，没有额外的深水区接口；
- 线路二当前是死域名（站点自己也没换），只作为备用入口存在。
