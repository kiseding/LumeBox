# 液态导航调节说明

进入“设置 → 底部导航栏管理 → 液态玻璃细调”。上方始终显示实际底栏，可以按住、拖动、松手查看变化。滑动参数立即生效，松手后自动保存，重开 App 后仍保留。

页面按“预设 → 基础形状 → 跟手与回弹 → 效果与材质”分组。预设提供三套一键组合：推荐（当前默认）、规则通透（规则胶囊 + 更清澈中心 + 克制色散）、柔和自由（圆角矩形 + 自由形变 + 更白中心）。预设只改液态参数，不动导航尺寸、排序、主题与图标设置；点“恢复液态参数默认值”回到“推荐”组合。

原页面的白度、磨砂、边缘高光、阴影、左右留白、高度、离底距离及动效时长继续有效。“液态动效总开关”与原“点击弹跳动效”是同一个开关。六类效果均可单独关闭：水滴鼓起、拖动拉伸、胶囊联动、按压变清透、透镜折射、高光与阴影联动。

“基础形状”可选胶囊、圆角矩形、椭圆、圆形，并对选中底座与按住时的透镜同时生效。“自由形变”关闭时保持规则轮廓；开启后才允许拖动拉伸、拖尾与倾斜。形状只影响视觉，点击目标与页签宽度不变。

| 新参数 | 默认 | 范围 | 调整后的感觉 |
| --- | --- | --- | --- |
| 形状宽度 | 100% | 60～150% | 基础形状的宽度倍率 |
| 形状高度 | 100% | 60～150% | 鼓起后的高度倍率；圆形会自动保持正圆 |
| 圆角程度 | 100% | 0～100% | 仅圆角矩形生效：100% 接近胶囊，0% 接近直角 |
| 按压响应时间 | 100 毫秒 | 50～400 毫秒 | 越小按下鼓起越快 |
| 回弹阻尼 | 58% | 30～100% | 越低回弹越明显，原动效时长继续控制速度 |
| 水滴鼓起高度 | 43% | 0～100% | 水滴超出下方胶囊的幅度 |
| 按压横向膨胀 | 72% | 0～150% | 按住向左右撑开 |
| 上下跟手幅度 | 9% | 0～25% | 随手指上下轻微偏移 |
| 拖动拉伸幅度 | 65% | 0～120% | 快速拖动、离落点较远时拉长 |
| 拖尾收窄程度 | 55% | 0～90% | 尾部变细，随拖动方向转向 |
| 胶囊横向伸缩 | 0% | 0～6% | 底座胶囊额外的左右伸缩（辅助效果，默认关闭） |
| 胶囊纵向伸缩 | 0% | 0～18% | 底座胶囊额外的上下伸缩（辅助效果，默认关闭） |
| 整条按压放大 | 3.4% | 0～8% | 按住时整条底栏（含图标文字与透镜）一起放大；参考实测约 3.4% |
| 按压整体提亮 | 18% | 0～40% | 按住时提高底座白度，参考录屏按压后底栏会变白 |
| 局部收腰 | 0% | 0～100% | 参考实测未证实真实收腰，保留为默认关闭的附加效果：按住时底座上下缘向触点轻收 |
| 按压磨砂减弱 | 62% | 0～100% | 按住变清晰，松手恢复磨砂 |
| 按压白度减弱 | 24% | 0～100% | 按住时减少原有白色遮盖；全白端点仍保持全白，全透端点按压时会被“按压整体提亮”率先提亮 |
| 折射放大强度 | 100% | 0～250% | 图标、文字和背景一起放大、弯曲 |
| 边缘彩色折光 | 45% | 0～250% | 边缘轻微红蓝折光，零为关闭；近白背景会自动收敛 |
| 透镜中心提亮 | 42% | 0～100% | 透镜中心向白色提亮，接近参考里的白玻璃；0% 保留原色 |
| 透镜中心降饱和 | 30% | 0～100% | 中心颜色向灰度收敛，配合提亮得到“清但有玻璃”的质感 |
| 清澈过渡宽度 | 30% | 5～60% | 透镜边缘从清澈过渡回磨砂的宽度（相对透镜高度） |
| 透镜核心玻璃厚度 | 6% | 0～50% | 核心处保留的极薄玻璃层；0% 完全通透，越高越接近磨砂 |
| 按压高光增强 | 60% | 0～150% | 在原高光之上增强，原高光为零则不额外开启 |
| 按压阴影增强 | 320% | 0～400% | 相对原阴影增强，原阴影为零时仍无阴影 |
| 背景明暗联动 | 50% | 0～100% | 背景越暗玻璃越偏白以保住文字对比度；亮背景回到设定白度 |
| 减少透明效果 | 关闭 | 开关 | 更白的底座、收敛的折射；iOS 系统“降低透明度”开启时自动生效 |

2026-10-20 调参说明：透镜宽度、鼓起高度、边缘折光与投影默认值已按参考录屏实测调整（透镜约占底栏宽度 28–31%、高约 1.2 倍、彩色折光收敛、投影加深）；透镜中心同时提亮并轻微降饱和，接近参考里“清但有玻璃、中心偏白”的观感。新增的提亮、降饱和、清澈过渡宽度、核心玻璃厚度与背景明暗联动参数会按效果分组自动出现在本页；旧配置只补默认值，不会被覆盖。完整差异与后续项见 [液态玻璃局部清澈接入](2026-10-20_液态玻璃局部清澈接入.md)。

2026-10-20 基础形状：新增胶囊／圆角矩形／椭圆／圆形四种基础形状与“自由形变”开关；形状宽度、高度、圆角程度三个参数位于“基础形状”分组。旧配置默认胶囊 + 自由形变开启，保持原有观感；切换形状不会改变页签点击区域与排序。

2026-10-20 按压几何：按参考录屏实测，按压时改为**整条底栏（含图标文字与透镜）一起放大约 3.4% + 整体变白**；原“胶囊横向/纵向伸缩”降为默认 0 的辅助效果。参考帧核对没有测到底座真实收腰，因此没有按旧方案实现“局部收腰”，截图里的内收来自透镜台阶、投影和边缘变淡。

建议先保留默认值，只改一类观察。恢复本页默认值只恢复液态细调，保留原导航尺寸、白度、磨砂、排序和动效时长。

按压预览不立即切页，松手才确认页签；触摸被系统取消时回到原页。减少动态效果开启后不运行按压、拉伸与回弹。透镜不重复创建图标或触摸区域。

Android 模拟器已检查五项、三项布局、按住变形、设置页实际预览。回归覆盖触摸取消、减少动态效果、白度端点、参数持久化及所有参数最大值。截图在 `build/dock-reference-20261019/`；iOS Metal 折射和真机手感尚待 IPA 验收，不能据安卓截图声称完全一致。
