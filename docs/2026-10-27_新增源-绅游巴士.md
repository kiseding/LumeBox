# 新增源：绅游巴士（gamebus001.cc）

2026-10-27 · `sources/comic/gamebus.js`（H 漫）、`sources/video/gamebus.js`（短片）

## 1. 站点形状

`https://gamebus001.cc/` 是 Quasar/Vue 的 SSR 站（Cloudflare 前置，页面带 CF 的 challenge 脚本），三个板块：

| 板块 | 路径 | 内容 | 本源 |
|---|---|---|---|
| 漫画 | `/comic`、`/comic/{id}`、`/chapter/{chapterId}` | H 漫，一话几十到三百多页 webp | `sources/comic/gamebus.js` |
| 短片 | `/video`、`/video/{id}` | HLS 短片（fMP4） | `sources/video/gamebus.js` |
| 游戏 | `/product`、`/product/{id}` | PC 游戏下载（`/cloud-link/{id}` 取网盘） | **不做**：LumeBox 没有游戏板块，硬做成图源只会是假源 |

首页的 `window.__INITIAL_STATE__` 只带首屏数据；列表实际是客户端调接口，接口表是从 `/assets/index-Cq4bvF8R.js`
里扒出来的（`ve({url:'/comic/page/'+e.page, method:'POST', data:e})` 这种），全部挂 `/api` 前缀。

## 2. 接口清单（实测）

| 用途 | 请求 | 说明 |
|---|---|---|
| 漫画列表 | `POST /api/comic/page/{page}` | body `{"keyword":"","page":N,"pageSize":30,"sort":"last_chapterAt"}`；`sort` 实测可用 `last_chapterAt` / `createdAt` / `views` / `likes`（`hot` 会 500）；`keyword` 是站内搜索（`NTR` → 34 条）；返回 `{list,total,page,pageSize}` |
| 漫画详情 | `GET /api/comic/{id}` | `title/cover_url/description/author/tags[]/views/last_chapterIndex` |
| 漫画选集 | `GET /api/comic/chapters?comicId={id}` | `{list:[{id,title,order_index,is_locked,pages}]}` |
| 漫画正文 | `GET /api/comic/{chapterId}/pages` | `{chapter:{pages:[{image_path,order_index}]},prev,next}` ★ 比解 `/chapter/{id}` 那 145 KB 的 `__INITIAL_STATE__` 干净得多 |
| 短片列表 | `POST /api/video/page/{page}` | body `{"page":N,"pageSize":30,"sort":"views"}`；`sort` 实测 `views`（最多播放）/ `hot`（热门）；`keyword` 可用 |
| 短片详情 | `GET /api/video/{id}` | `hlsUrl/coverUrl/duration/category/tags[]/role/views/vipOnly/price` |
| 短片分类 | `GET /api/video/categorise` | 只有 `网红福利` / `国产自拍` 两个，**但列表接口不认任何分类/标签参数**（`categoryId`/`tagId`/`categoryIds` 全部被忽略，total 恒为 5279），所以本源不拿它当分类 |
| 图片标签 | `GET /api/tag/comic` | 41 个标签，同样不能服务端过滤，不做分类 |

分页：漫画 1265 部、短片 5279 条，`pageSize` 可提到 30（默认 10）。

## 3. 媒体

- 图片：`https://image.gamebus001.cc/comic/…/1.webp`，实测 **200 + image/webp**（单张 248 KB），不需要 Referer；
- 短片：`https://image.gamebus001.cc/video/{日期}/{批次}/index.m3u8`，实测 **200 + application/x-mpegurl**；
  清单是 fMP4（`#EXT-X-MAP: URI="init.mp4"` + `seg_000.m4s`，相对路径、无 AES key），
  首个分片实测 **200 + video/mp4（5.7 MB）**，同样不需要 Referer。
- `vipOnly` 的条目源站只有付费墙：列表里标 `VIP`，`content()` 给可读错误并附源站页面，不做任何绕过。

## 5. 限制

- **不能按分类/标签过滤**：站点的列表接口只吃 `page` / `pageSize` / `sort` / `keyword`，所以本源只给排序 + 搜索；
  站点 UI 上的分类芯片是前端筛的，脚本拿不到全量就没法复刻。
- **游戏板块不做**：`/product` 是下载站（`/cloud-link/{id}` 出网盘），LumeBox 没有对应板块。
- 页面正文里夹着广告跳转（`dearestie.xyz`、`12.kg` 等），脚本一律不碰；全站 18+。
