# 三个站点的排查结论（rdd / yhh / raq）与新增源：玉羞园

2026-10-27 · 三个域名一次过筛，其中只有一个能直连取流

## 1. 三个站是什么

| 域名 | 名称 | 架构 | 结论 |
|---|---|---|---|
| `https://rdd.serz7722.icu/` | 色忍者TV | 苹果CMS v10（`template/the1`，Cloudflare） | **有 VIP，服务端托管播放器**，匿名拿不到流 |
| `https://yhh.yxy881p.icu/` | 玉羞园 | xvideos 镜像（原版模板 + xvideos CDN） | **无 VIP、无登录**，媒体直连 → 已做源 |
| `https://raq.fmav631p.icu/` | 疯猫av国产影片 | 苹果CMS v10（同为 `the1`，与 rdd 同站群：共用「三千佳丽 / 91福利社 / AI短剧导航 / b站入口」那批导航） | 同 rdd，**播放走同一个 vipplay 网关** |

## 2. rdd / raq：VIP 挡在服务端托管播放器（无绕过口子）

这两站是同一套程序、同一批广告站群，内容库各自独立（rdd 的 JSON 接口报 total = 295,997）。

结构：

```
列表   /list-1.html、/week_hot-1.html、/month_hot-1.html、/detail-{id}.html
播放   /video-{sid}-{id}.html   （sid=11 才有；其它 sid 404）
JSON   /index.php/ajax/data?mid=1&limit=N&page=N    → {code:1,total,pagecount,list:[…]}
搜索   /index.php/ajax/suggest?mid=1&wd=关键词
```

播放页里是标准 maccms 的 `player_aaaa`：

```json
{"flag":"play","encrypt":0,"trysee":0,"points":1255141,
 "url":"https://vipplay.5g82t.xyz/__1255141.mp4__/video.m3u8&vod=1255141",
 "from":"ck91player"}
```

按《VIP处理约定》逐条试过，全部不通：

| 打法 | 实测结果 |
|---|---|
| 页面层直取 | 详情页/播放页 HTML 里**没有任何 m3u8/mp4**，只有 `player_aaaa` 的网关地址 |
| CDN 路径可推导 | `vipplay.5g82t.xyz`、`ai.5g82t.xyz` 上试了 `/{id}.m3u8`、`/{id}.mp4`、`/__{id}.mp4__/index.m3u8`、`/video/{id}/index.m3u8` 等 8 种形态 → 全部 302 到 `ai.5g82t.xyz/404.m3u8`（171 B 占位清单） |
| 签名/试看复用 | `trysee=0`、`vod_trysee=0`，站点没开试看；带 `&vod=` 的正确形态直接 302 到广告域名 `2026-10-09.urldance.com/6d/?5g82t.xyz` |
| 接口越权 | `/index.php/ajax/data` 与 `/api.php/provide/vod/`（回 `closed`）都**不下发 `vod_play_url`**，只有 `vod_points_play`（内部播放 id） |
| 同库镜像 | 导航里的 8 个「帝王会所/千度导航/三千佳丽/91福利社/…」都是**导航/落地页**，不是同库内容站；同 id 无法在别处取到 |

抽样 8 条播放页，`from` 全是 `ck91player`、主机全是 `vipplay.5g82t.xyz` → 只有一条服务端网关，没有可切线路。

结论：**这两站的 VIP 是"服务端托管播放器 + 会员校验"，没有签名复用/路径推导的口子**，匿名无法取流。按约定第 6 条处理：源可以列内容，但播放只能给可读错误或转网页。本次没有为它们建源（列出 30 万条却一条都放不了，体验比不做更差），如实记录在此。

## 3. yhh（玉羞园）：xvideos 镜像，直连可播 → 已做源

`https://yhh.yxy881p.icu/` 完全套用 xvideos 的前端（`assets-cdn77.xvideos-cdn.com` 的 jQuery/播放器、`thumb-cdn77` 缩略图），视频文件就是 xvideos 的 CDN：

```
setVideoUrlHigh → https://mp4-cdn77.xvideos-cdn.com/{uuid}/6/mp4_sd.mp4?secure=…
HLS            → https://hls-cdn77.xvideos-cdn.com/{uuid}/6/hls_low.m3u8
```

实测：hls master 200 + `application/vnd.apple.mpegurl`（206 B）；mp4 200 + `video/mp4`（**93,026,181 B 整片，能直接下**）。

结构（0 基分页，注意别写错）：

| 用途 | 路径 |
|---|---|
| 首页（最新） | `/` （48 条/页） |
| 最新翻页 | `/new/{n}`，n = 页码-1（`/new/1` = 第 2 页；`/new`、`/new/0` 都 404） |
| 最佳 | `/best`、`/best/{n}` |
| 中文字幕 | `/lang/chinese`、`/porn/{n}`（`/porn/0` 也可） |
| 分类 | `/c/{Slug}-{id}`、`/c/{Slug}-{id}/{n}`（27 条/页） |
| 搜索 | `/?k=关键词&p={页码}`（p 从 1 起） |
| 详情 | `/video.{eid}/{videoid}/0/{slug}`，短链 `/video.{eid}/{slug}` 也行 |

两种卡片版式要同时兼容：
- 首页：`<a href="/video…"><img data-src="https://thumb-cdn77…">`，标题在 `<p class="title"><a title="…">`
- `/best`、`/lang/chinese`：`<a class="thumb-link">` + `<picture><source data-srcset>` + `<div class="title" title="…">`

源：`sources/video/yuxiu.js`（`yuxiu_video`），验证：

```
node tools/lume-source-check.mjs sources/video/yuxiu.js --keyword 中文   → PASS
home 3 块（最新/最佳/中文字幕）/ categories 41 项 / list 48 条 hasMore /
搜索 27 条 / detail ok / chapters 1 / content 给 hls_low.m3u8 探活 200（206 B master）
--page 2 正常（listPath 映射：new→/new/1、best→/best/1、chinese→/porn/1、cat→/c/{slug}/1）
```

## 4. 限制

- 玉羞园的内容是 xvideos 公共库，`secure=` token 带时间戳（约 1 小时后失效）→ 必须现取详情页，不能缓存太久；脚本详情缓存 10 分钟，够用。
- 分类 id 是 `Slug-数字`（如 `Anal-12`），换站/改版时按首页导航重新解析（脚本已按 host 缓存 6 小时）。
- rdd / raq 若以后播放网关换域名或开试看，重新按约定第 2、3 条打一遍即可；线索是 `player_aaaa` 里的 `from` 与 `url` 主机。
