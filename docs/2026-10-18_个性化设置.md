# 个性与界面新增设置

2026-10-18，依据用户三张参考图新增自定义主题色、字体与字号、自适应颜色。沿用现有主题、设置存储和图片管线，不另建一套导航或图源加载逻辑。

## 使用位置

设置 → 个性与界面：

- **主题色 → 自定义颜色**：点按/拖动饱和度与明度色板，调整色相，或输入六位 HEX（可带 #）。圆点预览与输入值同步；无效值不能确认。“使用这个颜色”后全局生效，取消不覆盖原设置。切回预设颜色保留上次自定义值。
- **字体与字号**：在系统字号基础上设置 70%–160% 界面缩放，恢复 100%；普通/粗体切换，斜体可叠加；系统字体、本机字体导入和长按删除。主题样式中的标题和按钮随字重设置变化，页面明确指定的特殊文字样式仍保留其设计。小说正文的独立排版设置继续保留。
- **自适应颜色**：开启后，来源首页根据顶部第一项推荐封面取主色，应用到首页局部主色与淡色背景；无封面、灰度封面或加载失败回到手动主题。当前首页为网格/列表，没有新增参考应用的轮播组件；切换来源、筛选、刷新推荐后重新取样。

## 存储与资源

外观保存至应用支持目录 `appearance_settings.json`，新增字段独立校验，旧配置保持原默认行为。根应用响应设置变化，字号与系统缩放相乘，保留系统非线性无障碍缩放，不要求重启。

字体支持 `.ttf` / `.otf` / `.ttc`，单文件上限 32 MB。校验 SFNT/TTC 表目录与文件边界，加载成功再保存；按 SHA-256 去重。字体文件在本机 `custom_fonts/`，不进入现有备份和 iCloud 文件清单；备份可保留选择 ID，另一台机器没有相应文件时使用系统字体。删除移除本机文件和选择；已加载的原生字体缓存由引擎管理，进程退出后释放。

自适应取色沿用原封面 URL、请求头和图片管线，按 64 像素宽度解码取样，取样后归还引用；不把取色写回全局手动主题，不触发导航壳反复重建或图源重新请求。关闭后立即停止应用取色，迟到结果不能覆盖新封面。
