# Python 与模块源接入

日期：2026 年 10 月 20 日。面向 iOS；现有安装包 `1.0.171` 不含本次功能。本次不生成 IPA。

Python 使用通用 Spider 兼容层，适用范围由接口与依赖决定，不按五个示例脚本的名字分支。不能保证所有第三方客户端的 Python 扩展都可运行；专用宿主接口、系统能力和第三方依赖仍有边界。

## 导入和使用

1. 视频页打开源选择器，点添加，选择 **Python 源** 或 **模块源**。
2. 选择本地 `.py`、`.mjs`、`.cjs`、`.js` 文件，也可以使用订阅地址、地址清单或剪贴板。
3. Python 与模块源分别显示在 PY／模块分类；点击后使用现有分类、搜索、详情、选集及播放器。
4. 导入结果会显示能检测到的 Android 专属或缺失依赖。必需导入失败会点名缺少的模块，不写入半成品源。

Python 代码在 App 进程内执行，能够访问 App 允许的资源。只导入可信来源。各源有独立脚本命名空间、会话和内存缓存；这不等同于 JS 引擎的隔离沙箱。

源身份随脚本文本保存。无元信息的脚本自动生成 id：订阅采用来源地址，本地采用文件名。更新同一来源或同名文件保持 id；不同本地文件如有同名，应主动声明不同 id。备份、恢复、启停、删除与订阅刷新复用现有链路。

## Python 兼容范围

| 类别 | 支持范围 | 边界 |
| --- | --- | --- |
| 脚本入口 | `Spider` 类、`spider` 对象、模块级函数 | 至少提供详情、播放，以及首页／分类／搜索之一 |
| 接口别名 | `homeContent`、`homeVideoContent`、`categoryContent`、`detailContent`、`searchContent`、`playerContent` 及对应 `get…Content`；另支持 `home`、`homeVod`、`category`、`detail`、`search`、`play` | 返回值采用 Spider 常见字段约定 |
| 参数 | 无参数初始化、两／三参数搜索、常见分类参数顺序、默认整数页码和关键字参数 | 无法自动推断任意私有接口的语义 |
| 网络 | Requests、Session、urllib、http.client、HTTPX 同步和异步客户端 | 复用 App 网络队列、源 UA／Cookie／代理与证书设置；上传使用完整字节体 |
| HTML | BeautifulSoup、HTML5 解析、常用 `lxml.etree`／`lxml.html` 方法、XPath 1.0、常用 PyQuery CSS 方法 | `lxml`／PyQuery 接口由兼容层提供；未覆盖的方法会报错 |
| 加密 | AES ECB／CBC／CFB／OFB／CTR／GCM、ChaCha20／XChaCha20 Poly1305、PKCS7、常见 MD5／SHA／HMAC 接口 | 属于常用 Crypto 接口子集；原生第三方 Crypto 模块不自动安装 |
| 宿主辅助 | `fetch`、`post`、`html`／`htmlParser`、`getText`、`getArray`、`regStr`、`cleanText`、带过期时间的内存缓存 | 缓存随运行时释放，不持久化 |
| 编码 | UTF-8、UTF-8 BOM、由 Python 编码声明指定的 GBK 等编码 | 非 UTF-8 字节保留后由 CPython 解码 |
| 播放 | 多线路选集、请求头、音频地址、网页解析标记 | `parse=1` 转入已有 WebView 解析页；真实站点仍可能需要验证码或会话 |
| 生命周期 | 延迟初始化、后台串行执行、CPU 超时检测、超时重建、源停用和删除释放 | Python C 扩展阻塞和任意线程不能获得 JS 沙箱同等的资源限制 |

底层采用 BeeWare Python Apple Support `3.13-b13`（CPython 3.13.11）。下载包 SHA256：`d1f95f95137a4b91dc0cbe9b99ddfc0a78918dde883c7fbe7147074a5e715274`。纯 Python 依赖版本、来源与 SHA256 固定在 `tool/python_packages.lock.json`，构建时校验，不在手机上运行 pip。

原生接入依据：[CPython iOS 嵌入说明](https://docs.python.org/3.13/using/ios.html)、[Python Apple Support 3.13-b13](https://github.com/beeware/Python-Apple-support/releases/tag/3.13-b13)。

## 模块格式

模块目前采用**单文件 JavaScript 源对象协议**。支持：

- `export default { categories, list, detail, chapters, content }`；
- `export function list(...)` 等具名导出，以及 `export { localName as list }`；
- `module.exports = { categories, list, detail, chapters, content }`。

各方法采用现有 LumeSource 契约，完整接口见 [源开发指南](lumesource-guide.md)。可以在导出对象或 `// LumeSource: {"id":"...","name":"..."}` 头部声明元信息。

跨文件 `import`、重新导出依赖和多文件包需先打包成单文件；错误提示会说明。T4、Android APK／DEX 和其他客户端的私有模块协议仍需各自的适配器。

## 常见不兼容情况

- `java`、`jnius`、`dalvik`、`chaquopy`：需要 Android 宿主或另外提供后端；导入时会提示能检测到的依赖。
- `getProxyUrl()`／本地服务：现有兼容层不提供 Python 本地代理服务；此路径会提示使用外部后端。
- 缺少第三方模块：必需依赖在导入时失败；延迟或可选依赖会列入兼容性说明。尚不支持用户安装任意 wheel、辅助文件包或原生扩展。
- 普通命令行 `.py`：如果没有源接口，无法自动变成分类、搜索和播放源。
- 网页或接口改版：引擎兼容并不保证上游站点持续可用。
