# 导入 HTML 网页主页

在视频页打开源选择器，进入「网页」，点右上角「+ → 导入 HTML 文件」，选择 `.html` 或 `.htm`，确认名称后保存，再点主页卡片打开。也可从「添加视频源 → 网页主页」进入同一对话框。

需要安装包含本次代码的新版 App；旧版只有网页地址输入框。文件须为 UTF-8、自包含 HTML，最大 2 MB。正文保存进视频板块设置，备份会带上；不依赖系统文件选择器的临时路径。长按排序、编辑名称、更换文件、删除继续沿用网页主页列表。

## 从页面播放内容

- 直播合集：页面负责解析直播流，`fm.play` / `fm.vodInline` 把地址及 Referer、User-Agent 交给 LumeBox 现有播放器。格式支持取决于所选内核。
- 玩偶聚合：`fm.pan.play` 或 `fm.play('push://…')` 打开猫源选择。选择支持分享链接的已启用视频猫源后，交给该源的详情、目录、选集和播放流程。账号登录、提取码处理和分享解析由该猫源提供。普通采集站不一定具备此能力。
- 没有猫源时提示先添加和登录，不把网盘网页当作视频直链。磁力也只转交支持它的猫源，没有内置 BT 下载器。
- 网页申请融合模式时隐藏原生顶栏，右上角「…」始终能恢复工具栏，随后可返回、刷新。页面里的外部 HTTP(S) 链接进入另一张普通网页，不获得兼容接口。

## 本次支持的接口

仅用户导入的本地 HTML 注入兼容层。普通网址维持原来的 WebView 行为。

| 接口 | 行为与范围 |
| --- | --- |
| `fm.req(url, options)` | 宿主网络请求；支持 method、headers、body、timeout（1–90 秒）、responseType（text / json）。返回 ok、status、headers、body、url；请求体上限 1 MB，响应上限 8 MB。使用 App 全局网络设置，不保证改变系统 VPN 路由。 |
| `fm.res(url, options)` | 同步返回图片代理地址，传递图片请求头；不代理可执行 HTML。支持直接返回 data 图片 / blob。 |
| `fm.play(url, title, options)` | HTTP(S)、RTMP(S)、RTSP 媒体进入现有播放器，传递 options.headers；push、磁力和常见网盘分享链接转交猫源。 |
| `fm.vodInline(vod)` | 选择 mark 对应剧集，或首集；调用网页的 `__fmWebHomeInlineResolver`，再以原生全屏播放器起播。本次没有实现原网页中的嵌入式小窗或网页剧集自动连播。 |
| `fm.cache.get/set/remove` | 按主页与命名空间隔离，持久保存。每页缓存上限 1 MB；删除主页同时清空。 |
| `localStorage` | getItem、setItem、removeItem、clear、key、length；同步读取、异步顺序写入同一页的持久缓存，刷新及重开恢复。 |
| `fm.ui.setChrome/restoreChrome/getViewport` | normal / edge / fullscreen、当前安全区；派发 fmviewport 事件。其他原 App 专有状态栏配色参数暂未实现。 |
| `fm.config()` | 返回 driveCheck=false；不会把未检测的网盘链接隐藏。 |
| `fm.pan.check()` | 返回 uncertain，未提供网盘有效性检测。 |
| `fm.pan.play()` | 把分享链接和提取码传给用户选择的猫源。是否可解析须以所选源实际结果为准。 |

兼容层在作者脚本之前注入，并派发 fmsdk 事件。网页从仅监听 127.0.0.1 的随机端口、随机路径加载；跨 Origin 调用拒绝，图片代理限制 MIME。网页缓存不提供读取其他主页设置、弹弹play 凭证或 App 文件的接口。

不支持依赖同目录独立 JS/CSS/图片的多文件网页包；这些资源需要作者嵌入 HTML 或使用绝对网络地址。本次不会把三方 HTML 内置到安装包。

## 验证与证据

| 证据 | 已验证结论 | 使用边界 |
| --- | --- | --- |
| `test/web_home_bridge_test.dart` | HTML 保存与重开、编码/体积校验、请求头与 POST、JSON、403 状态、缓存隔离、loopback HTTP、图片代理限制、真实 Node JavaScript 调用至 Dart 服务 | 模拟远端 API 响应；未证明真实直播平台、网盘站或 iOS WebView 可用 |
| `test/video_source_picker_test.dart` | 系统选择文件 → 自动命名 → 保存 → 本地主页卡片 | Flutter 界面测试，系统选择器采用替身 |
| `test/web_home_sources_test.dart` | 原有网址主页存储兼容 | 保留旧数据 |
| `tool/verify_web_home_html.mjs` | 用户提供的 lzxwwogg.html、玩偶聚合.html、各大平台直播合集.html 格式与脚本语法通过 | 只做语法检查，不等于网页运行或网络播放验收 |

运行本次专项检查：

```powershell
flutter test --no-pub test/web_home_bridge_test.dart test/web_home_sources_test.dart test/video_source_picker_test.dart
node tool/verify_web_home_html.mjs 'C:\path\home.html'
```

真实 SDK 联调测试需要 Node.js。仍需 iPhone 实测：系统 Files 导入、三份页面实际渲染、跨域请求、直播起播与切内核、融合模式的安全区和键盘、已登录网盘猫源的选集与播放。403、地区限制、过期域名和站点风控仍取决于服务及设备网络。

## ReelFlow 的关系

[ReelFlow-Releases 的公开说明](https://github.com/Ryderwe/ReelFlow-Releases)描述了原生 iOS 影视客户端，包含猫源 / JSON / T4、搜索选集、播放和弹幕，与 LumeBox 的影视模块有明显重合。LumeBox 当前还包含漫画及普通 JS、Python、Rex 等源路线。该链接展示发布说明，没有展示可核对的实现源码；不能据此认定代码相同或直接复用其实现。
