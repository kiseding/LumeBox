# 参考项目接入与真机测试

基线为 `cdcfa49`。本次完善已有 Flutter、QuickJS、WKWebView 和播放器接入，不额外替换播放内核，不恢复全局原生玻璃，也不触发安装包构建。

## 在 App 中使用

### 导入 Kazumi XPath 规则

在视频源管理中导入 JSON 文件、粘贴规则正文，或添加规则 JSON 的订阅地址。也支持 KazumiRules 风格的 `index.json` 索引：按索引中的名称解析同目录规则，失效条目会被跳过，其余规则继续导入；每个源保存自己的规则地址，后续更新身份保持稳定。

适配内容包括 XPath 搜索、选集、POST 搜索、User-Agent、Referer，以及捕获媒体后交给现有播放器。没有捕获到直链时转网页播放器。规则本身没有首页推荐列表契约，因此这类源需要通过搜索开始使用，不会拼凑首页数据。

这是 XPath 规则适配，不能等同于完整 Kazumi 客户端：不实现其全部 HTTP/JSON 规则、私有解析器或 HLS 广告处理。API 版本超过 5、缺失必需字段或已被维护者标记停用的规则会报出原因。规则站点本身的可用性仍须真机测试。

### 使用漫画图片服务器翻译

1. 打开“设置 → 阅读与播放 → 漫画翻译”。
2. 将“翻译方式”选为“漫画翻译服务器”，填写服务器根地址或完整 `/translate/with-form/image` 地址。
3. 选择翻译器。翻译器需要的密钥和模型预先配置在服务器上；App 不会把已有 AI API Key 自动发给这个地址。
4. 通用漫画选择 `48px`；日文漫画可选择 `mocr`，由服务器使用 manga-ocr。保存配置。
5. 在漫画当前页的图片工具中执行翻译，切回原图对照。界面显示服务处理与传输总耗时，原始图片和原始下载内容不被覆盖。

请求遵循上游 multipart 接口：`image` 为图片文件，`config` 为 JSON 字符串，包含 `ocr.ocr`、`translator.translator` 和 `translator.target_lang`。简体中文映射为 `CHS`，繁体中文为 `CHT`。仅接受有效 PNG 结果；HTTP 错误、非图片或过大响应不会作为译图应用。

服务器模式会上传整张当前图片。设备端 OCR 和 Apple Translation 模式继续保留，不会自动切换或后台上传。本次没有部署图片推理服务器、下载重模型或测得其真实识别精度；安装按上游 [manga-image-translator](https://github.com/zyddnys/manga-image-translator) 说明完成，需要能运行相应模型的电脑或服务器。

## 各项目的采用方式

| 项目 | 本次处理 | 边界 |
| --- | --- | --- |
| [Kazumi / KazumiRules](https://github.com/Predidit/KazumiRules) | 新增 XPath JSON 适配和索引订阅；复用网页宿主、请求头及更新通道 | 非完整 Kazumi 运行时；首页依靠搜索 |
| [Venera-Next](https://github.com/CyrilPeng/Venera-Next/blob/main/doc/api/js.zh.md) | 对照扩展接口，修复二进制请求的字节损坏，支持 ArrayBufferView 偏移；纠正“完全没有 DOM”的旧错误提示 | HtmlDocument 为选择器子集；没有新增 WebDAV 库、完整浏览器 DOM 或登录 UI |
| [native_liquid_glass](https://github.com/tienanh306201z/native_liquid_glass) | 参考覆盖层生命周期，底栏/局部玻璃在非当前路由、转场或隐藏时停止显示，恢复时复用原生视图 | 不再为每个列表项、按钮或输入框创建原生视图 |
| [InAppWebView](https://inappwebview.dev/docs/cookie-manager/) | 对照 Cookie 管理设计；继续使用已有 WKHTTPCookieStore 和会话同步，补足 HTTP 200 挑战页识别 | 未替换插件；CF 验证仍是人工完成，不能保证站点放行 |
| [Apple Translation](https://developer.apple.com/documentation/translation/) / [ML Kit](https://developers.google.com/ml-kit/language/translation) | 延续基线的语言分组、标题/简介译文缓存及图标入口 | 本轮没有引入 ML Kit 或额外模型包；跨平台接入仍属独立工作 |
| danmu_api | 保留已部署的弹弹play兼容服务，复验跨实例编号测试 | 没有重新部署或声称所有上游视频都有弹幕 |
| [canvas_danmaku](https://pub.dev/packages/canvas_danmaku) | 对照直接绘制和空闲停帧设计，现有 Canvas 弹幕增加后台、隐藏和长空档停帧 | 沿用现有绘制层；绘制优化不改变接口零条结果 |
| [manga-image-translator](https://github.com/zyddnys/manga-image-translator/blob/main/server/main.py) / [manga-ocr](https://github.com/kha-white/manga-ocr) | 新增可选服务器图片翻译及 mocr 模型选择、原图对照和耗时显示 | 模型在服务器运行；不能视为已完成服务器部署或识别质量评测 |
| [media_kit](https://github.com/media-kit/media-kit) | 继续使用现有播放内核，规则直链进入已有请求头和播放路径 | 未替换内核 |
| [FlareSolverr](https://github.com/FlareSolverr/FlareSolverr) | 保留为独立服务器浏览器方案的研究项 | 未接入或部署，不能代替当前人工验证 |

## 验证依据与真机路径

| 证据 | 可得结论 | 出包后的复测路径 |
| --- | --- | --- |
| `test/kazumi_rule_test.dart`：实际 QuickJS 调用、索引部分失败、版本身份保持 | 规则进入生产 JS 宿主，POST/Referer 及网页播放回退契约成立 | 导入可用规则，搜索含空格和中文的片名，打开详情、选集与播放 |
| `test/js_sandbox/venera_compatibility_test.dart`：本地 HTTP 服务接收 `00 ff 80 41` 后回传 | 二进制上传及响应没有 UTF-8 转码损失，TypedArray 切片偏移保留 | 对照漫画源的图片、请求头和加密数据接口 |
| `test/waf_response_fingerprint_test.dart` | 200 状态明确挑战页可识别，普通防盗链 403 和文章文字不误判 | 巴卡、hanime1 完成人工验证后刷新；原 193 验证页面交互未被替换 |
| `test/dock_native_glass_test.dart` | 普通弹窗盖住底层原生玻璃，关闭时复用平台视图 | 连续打开设置、输入弹窗并返回，观察透底、闪烁与键盘 |
| `test/danmaku_render_test.dart` | 后台、隐藏页面和空档不持续请求动画帧 | 播放、暂停、拖进度、切后台、恢复、切集，观察同步与温度 |
| `test/manga_translation_client_test.dart`、图片工具设置持久化测试 | HTTP 表单和图片结果校验、配置保存符合预期 | 用同一页比较设备端与服务器 mocr，记录文字准确率及总耗时 |

Cloudflare Workers 弹幕服务的独立仓库另有 `tools/stateless-episodes.test.mjs` 四项通过。它们验证跨实例编号、篡改拒绝、旧编号和缓存回退，不代表已实测所有平台。

以上为桌面测试与接口契约验证。iPhone 的 CF 放行、Apple Translation 实际语言包调用、服务器模型质量、帧率和温度，需要用户自行出包后的真机结果。
