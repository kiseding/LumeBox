# 诊断包结论：首页「请求已取消」风暴与播放诊断字段

## 诊断包（1.0.248 / iOS 27.2）看到的现象

- `video:lu320_video` 的 `LumeSource.home` / `list` 在 30 秒内失败 **30 次**，全部是
  「脚本错误：请求已取消」——即请求在**已取消的作用域**里反复发起，不是网络错误。
- 同期多个站点取图标出现 `TimeoutException` / `NSURLErrorDomain -1005`（连接丢失）/
  `HTTP 429`，说明到源站的网络本身也不稳。
- `diagnostics.json` 里 `playback` 为**空数组**：这份包里没有一次播放记录，因此看不到
  媒体地址是直连还是本地代理、是 HLS 还是 MP4。

## 已修

1. **首页取消风暴**：`SourceHomeView._load` 现在记录「正在加载的源」，
   同一源的非强制重入直接复用、不再 `cancel('home')` 重启；
   被替换/取消的瞬时错误仍只自动重试一次（重试前先让出去重标记）。
2. **播放诊断补两项**（不含路径，只有类型）：
   - `stream`: `hls` / `file`
   - `loopback`: 媒体地址是否走 Python 本地代理（`127.0.0.1` / `localhost`）

   下次复现「缓冲中很久」后导出诊断包，`playback[].stage == "media-load"` 就能直接看出
   是「HLS 被固定最高码率」还是「Python 代理整包转发」还是「直连 MP4 源站慢」。
