## 二、站点结构变化（本次真正的 bug）

旧源按 `/listinfo-19-0.html`（里番）+ `/moehome-1-{id}.html` 解析。新站把内容拆成了两类：

- **图集频道**（有 `/moehome-{类型}-{id}.html`）：
  - 9 最新、1 COS、2 CG、3 本子、4 套图；每页 60 条，分页仍是 `/listinfo-{分类}-{页码-1}.html`；
  - 详情路径带**类型**：`/moehome-1-{id}`（COS）、`/moehome-2-{id}`（CG）、`/moehome-3-{id}`（本子）、`/moehome-4-{id}`（套图）。
- **非图集**：里番 19、日漫 14、韩漫 15、3D 20、同人 21 现在是漫画阅读页（`/moehome-*` 一条都没有），
  福利 10 / 游戏 5 是别的栏目。

旧源只认 `moehome-1-`，所以只有 COS 能解析，其他分类全空。本次把解析器改成
`/moehome-(类型)-(id)/`，条目 id 用「类型-id」（类型 1 保持纯数字兼容老收藏），
分类收敛到 `9/1/2/3/4` 五个图集频道；不再把漫画页当图集列。

## 三、发布页写进源扩展功能

App 的 `action: openWebsite` 以前只会打开**当前站点**。本次加了可选 `url`（只收 http(s)、≤2048 字）：

```js
settings: [
  {
    key: 'publishPage', type: 'action', action: 'openWebsite',
    title: '打开发布页', url: 'https://02.uno/',
    description: '站点换域名时先看这里',
  },
  { key: 'note', type: 'info', title: '站点说明', description: '…' },
]
```

- 点按钮 → App 内嵌浏览器打开该网址（标题用按钮名，`loginMode: false`，不再显示登录提示）；
- 没填 `url` 时行为不变（打开当前站点）；
- 旧版 App 不认识 `url`，会退回「打开当前站点」——不会崩，只是少一步。

发布页地址**没有**写进 `mirrors`：它不是站点本体，切过去只会把列表打空。

## 五、限制

- 图集详情由站点 JS 渲染整组图，只能在 App 内嵌浏览器里看（沿用旧行为）；
- 分类是白名单（9/1/2/3/4）：站点如果新开图集频道，需要补进 `GALLERY_CATS`；
- acg.al / acg.bz / xpicvid.net 对 Node/App 的直连可能被 CF 挑战，主站 acgbay.com 目前直连可用。
