# 源线路与专用设置

App 提供统一控件并裁决规则，源声明支持的通用设置、可互换地址和本站扩展功能。优先级是 **App 类型与硬限制 → 用户在 App 中保存的有效选择 → 源建议默认值 → App 缺省值**。源不能通过声明改掉 App 通用设置的类型、名称、内置操作或范围。

站点、图床和视频 CDN 分开选择。每组最多 20 个地址，第一项是默认线路；用户自定义地址始终优先。更新源不会删除自定义地址、账号和用户设置。旧 `mirrors` 与旧 `settings` 继续有效；旧源无需改写才能使用。

## 源声明

可以写在 `// LumeSource: {...}` JSON 头部，也可以作为运行时对象属性。下面用运行时声明展示完整结构：

```javascript
var LumeSource = {
  id: 'example_video', name: '示例源', version: '1.0.0', category: 'video',
  settingsApiVersion: 2,
  requiresSettings: ['commonSettings', 'settingsActions', 'actionInputs'],
  endpoints: {
    site: ['https://main.example', 'https://mirror.example'],
    images: [
      {title: '主图床', url: 'https://img.example/covers'},
      {title: '备用图床', url: 'https://backup-img.example/pictures'}
    ],
    video: [
      {title: '线路一', url: 'https://video.example/hls'},
      {title: '线路二', url: 'https://backup-video.example/media'}
    ]
  },
  commonSettings: [
    {key: 'autoNext', default: false},
    {key: 'quality', default: 'hd', options: [
      {value: 'hd', title: '高清'}, {value: 'sd', title: '标清'}
    ]},
    {key: 'pageSize', default: 20, min: 1, max: 50},
    {key: 'playbackMode', default: 'auto'}
  ],
  settings: [
    {key: 'searchPrefix', type: 'text', title: '搜索前缀', default: '',
      group: '本站搜索', placeholder: '可留空', maxLength: 100},
    {key: 'refreshCategories', type: 'action', title: '刷新分类',
      group: '本站维护', action: 'source', inputs: [
        {key: 'count', type: 'number', title: '抽样数量',
          default: 2, min: 1, max: 5, integer: true}
      ]},
    {key: 'login', type: 'action', title: '网页登录', action: 'login'}
  ],
  // categories / list / detail / chapters / content 等入口照常实现。
  settingsAction: async function (args) {
    if (args.key === 'refreshCategories') {
      // args.settings / args.config 是校验后的当前表单值。
      // args.inputs 是本次动作输入，不写入长期设置。
      // 在这里调用本站的分类刷新逻辑；按钮不会自动保存整个表单。
      return {message: '已收到抽样数量：' + args.inputs.count};
    }
    throw new Error('未知操作');
  }
};
```

`endpoints.site` 与旧 `mirrors` 表达同一件事，前者存在时优先。主站列表使用网址展示；资源组的 `title` 可以自定义。镜像按 URL 保存选择，调整声明顺序不会选错；选中的地址被源作者移除时回到该组默认地址，自定义覆盖仍保留。

## 脚本读取

每次调用前更新只读的 `LumeSource.config`：

| 字段 | 含义 |
| --- | --- |
| `domain`、`mirrors`、`mirrorIndex`、`customDomain` | 已解析的站点地址与兼容字段 |
| `imageDomain`、`imageMirrors` | 图床当前地址与声明列表 |
| `videoDomain`、`videoMirrors` | 视频 CDN 当前地址与声明列表 |
| `settings` | 按声明校验后的专用参数；缺失或已失效的选项采用新默认值 |
| `commonSettings` | App 通用参数的最终值 |
| `sourceSettings` | 仅含本站扩展参数；冲突项、保留键不注入 |
| `account`、`password`、`cookie` | 原有按源账号与网络配置 |

站点请求建议以 `LumeSource.config.domain` 构造。可用同步辅助函数处理已有绝对地址：

```javascript
const poster = LumeSource.resolveUrl(originalPoster, 'image');
const media = LumeSource.resolveUrl(originalMedia, 'video');
const page = LumeSource.resolveUrl(originalPage, 'site');
const quality = LumeSource.config.settings.quality;
const pageSize = LumeSource.config.commonSettings.pageSize;
const prefix = LumeSource.config.sourceSettings.searchPrefix;
```

App 同时在 HTTP、网页渲染和数据契约边界处理已声明的线路：封面、章节图片及其请求头索引、视频默认地址和清晰度地址会使用对应资源组；作品 ID、章节 ID、正文文本保持不变。图片请求也会重新读取当前线路。切换后新的请求生效，已下载或命中缓存的同一图片不重复下载。

只匹配声明地址的来源和完整路径前缀。例如 `https://img.example/covers` 只替换 `/covers` 下的资源，不匹配 `/covers-other`。查询串和片段保留；`blob:`、其他站点和未声明的资源不改写。HTTP 请求遇到多个前缀时采用最长匹配，同长度优先按站点处理。

资源组必须由作者确认可互换。若不同 CDN 使用不同资源 ID、路径规则、签名或接口，应由源读取 `imageDomain` / `videoDomain` 后实现对应逻辑，并逐条验证。App 不探测、不猜测备用域名，也不自动重试另一线路。跨地址替换时移除旧的显式 Cookie / Authorization，Referer 按站点线路调整，由目标站点会话负责后续凭据。

## 声明 App 通用设置

`commonSettings` 只声明源支持的项目，不声明的项目不显示。`settings` 中与已启用通用设置同名的项会被屏蔽，用户旧值在有效时可以继承；之后独立保存在 App 设置值中。通用项目的 `title`、`type` 由 App 提供，源传入同名属性不会覆盖。

| key | App 控件 | 源可声明的内容 |
| --- | --- | --- |
| `quality` | 默认画质，下拉 | 本站支持的画质选项和默认值 |
| `imageQuality` | 图片质量，下拉 | 本站支持的图片质量选项和默认值 |
| `playbackMode` | 播放方式，下拉 | `auto` / `native` / `webpage` 支持范围和默认值 |
| `searchMode` | 搜索方式，下拉 | 本站搜索方式选项和默认值 |
| `pageSize` | 每页数量，整数 | 默认 20；App 硬范围 1–200，源可以缩小范围 |
| `autoNext` | 自动翻页，开关 | 默认关闭，可建议默认值 |

所有通用下拉保留 `auto`（自动）选项。`playbackMode` 不能添加其他取值或改名。无效的通用默认值回落；未知或重复的通用 key 拒绝导入。

App 在播放结果处执行播放方式约束：选择原生播放后，源返回网页解析线路会提示更换方式；选择网页播放时使用源的 `pageUrl`，没有时尝试 HTTP(S) 作品 ID。两者都不是有效网页地址时给出明确错误。其他业务参数由源读取后落实到请求或选集逻辑，例如每页条目数和画质参数；只写声明不会自动给站点增加相应功能。

App 通用设置区始终提供打开当前站点、测试源连接、清理源浏览缓存三个内置操作。源声明中的 `app_` 前缀，以及 `domain`、`cookie`、`account`、`password`、`capabilities` 等宿主保留键不能作为扩展设置覆盖宿主字段。源扩展只提供声明和固定回调，不加载源提供的原生控件。

## 添加本站设置和带参数按钮

最多 32 项，`key` 是以字母开头的字母、数字、下划线标识，最长 64 字符。支持 `toggle`、`select`、`text`、`number`、`info`、`action`；下拉最多 50 项，文本最多 4096 字符。`title` 是显示名，`description` 是说明。无效定义拒绝导入。

`group` 为连续设置项添加分组标题，`placeholder` 提供输入提示。文本支持 `required: true`、`maxLength`；数字支持 `min`、`max`、`integer: true`。限制在保存和执行按钮前检查，JS 适配器还会再次校验源动作参数。

`action` 项可带 `inputs`，最多 8 项，支持开关、下拉、文本和数字。点击后弹出输入窗；参数内不能再嵌套按钮或说明项。取消输入窗不执行回调；执行后输入只传入本次 `args.inputs`，不混入永久设置。

操作支持：`source` 调用固定入口 `settingsAction({key, settings, config, inputs})`；`login` / `openWebsite` 打开所选站点网页；`testConnection` 测试已保存配置；`clearCache` 清理该源浏览缓存。返回字符串或 `{message}`，以普通文字展示。只执行当前已声明的源动作；App 内置动作由宿主执行。按钮不会自动保存尚未提交的表单；取消不保存编辑值，但已执行的操作自身不会撤销。动作中读取未保存的编辑值应使用 `args.config` / `args.settings`；`LumeSource.config` 仍代表已保存配置。

设置值按源和板块隔离，声明更新与用户数据分开保存。声明移除的参数不再注入脚本，原值仍保留，避免源临时删项后丢失用户配置。旧版自定义站点设置在统一入口中继承，保存后迁移到同一规则。

## 协议与能力协商

新声明建议写 `settingsApiVersion: 2`；省略按 v1 兼容。高于当前版本、非法版本或未知必要能力会拒绝导入，并保留已有源。`requiresSettings` 可列出所需能力：`commonSettings`、`settingsActions`、`actionInputs`、`settingsGroups`、`resourceRoutes`。

源可以检查冻结的 `LumeSource.capabilities`：`settingsApiVersion` 为 2，`settingsFeatures` 为上述能力列表，`settingTypes` 为支持的六种控件类型。不能通过给 `LumeSource` 重新赋值或修改数组来覆盖这些宿主能力声明。能力声明用于检查是否兼容，不会赋予脚本额外原生权限。
