## SpankBang（spankbang.com）：Cloudflare JS 挑战 → 交付「薄壳」

- 直连：DNS 被劫持到 `173.252.248.244`，curl 回 000；`--resolve` 指到真实 CF IP 仍 403。
- 走本机代理：403 + `Cf-Mitigated: challenge` + `Just a moment...`（`cType: 'interactive'`，带 `__cf_chl_opt`）。
- 换头无效：桌面 Chrome 140 全套（UA + `sec-ch-ua` / `sec-fetch-*` + Accept + Accept-Language + Referer）、
  iPhone UA 都是同一个挑战页。
- 换路径无效：`/`、`/new_videos/`、`/trending/`、`/most_popular/`、`/categories/`、`/pornstars/`、`/s/teen/`、
  `/api/videos/new`、`/api/v1/videos/new`、`/ajax/videos`、`/sitemap.xml`、`/feed/`、`/rss` —— 全 403；
  **只有 `/robots.txt` 是 200**（CF 托管规则放行，里面没有片库数据）。`m.spankbang.com` 也 301 回主域再 403。
- 交付形态（`sources/video/spankbang.js`）：抓取层统一 `getText()`，403 / 503 / 521 或响应体含
  `Just a moment` / `cf-chl` / `__cf_chl_opt` → 抛 `NEED_WEBVIEW_VERIFY`；用户在 App 内置网页视图过完校验，
  App 把整套 Cookie（含 HttpOnly `cf_clearance`）存进该源会话，之后所有请求自动带上。
  `categories()` 走兜底路径表能过；解析规则用**不绑定 DOM** 的兜底锚点（`/<id>/video/<slug>` + `og:*` + 页面内 m3u8/mp4 扫描），
  一条都抽不到就抛可读错误，不返回空壳。
- **解析规则已实测（不是猜的）**：2026-10-25 用本机 Chrome（真实指纹 + 代理）在可见窗口里过完 CF 后，
  用 CDP 抓了三份真实 HTML：首页 `/`（671KB）、列表 `/trending_videos/`、详情 `/a5d50/video/porn`（878KB）。
  按这三页重写了整段解析，并**离线喂 HTML 跑通**：
  - 列表：`data-testid="video-item"` 切块 → `data-id` + `href="/{short}/video/{slug}"`（slug 含 `+`/`%xx`）+
    `img src=tbi.sb-cd.com` + `data-testid="video-item-length"`（如 `120m`）+ `…-resolution`（`HD`）；
    实测一页解析出 **82 条**、`hasMore=true`（`li.next` 判据）；
  - 频道（导航实测只有这三条）：`/new_videos/`、`/trending_videos/`、`/upcoming/`；
    分页 `/{频道}/{N}/`（首页 HTML 里 `data-page="2"`…`"32"`）；搜索 `/s/<词>/<N>/`；
  - 详情：`og:title` / `og:image` / `og:video:duration`（7245 秒）；
  - 播放：详情页内联 `var stream_data = {'m3u8': ['…master.m3u8?secure=…'], '720p': ['…-720p.mp4?secure=…'], …}`，
    实测 `master.m3u8` **直连 200 + `application/vnd.apple.mpegurl`**，`…-720p.mp4` **206 + video/mp4**；
    地址带 `secure=` 签名（含过期时间戳）⇒ 每次播放现取详情页。源里返回 3 条清晰度（720P/480P/240P）。
- **纯 HTTP 仍然过不去**：带 Chrome 导出的整套 cookie 用 curl 请求仍是 403（缺 `cf_clearance` / 绑 TLS 指纹），
  所以源的抓取层保持 `403 → NEED_WEBVIEW_VERIFY`，靠 App 网页视图过校验后复用 Cookie。
- 本机 `lume-source-check` 结果 `[FAIL]`（categories 4 项 ok，其余按设计报 NEED_WEBVIEW_VERIFY），
  这是环境限制不是脚本 bug。
