2026-10-28 · 结论：**xasian 可做源、但当前 IP 已被站点 WAF 封禁，未发布**；bh7564 是地址发布页，不做源。

### 接口形态：RPC over `/js`（不是 REST）

```
POST https://v2.cdn199.com/js
Content-Type: application/json
body: {"app":"xasian.org","version":"260901","uuid":"novalue","theLink":"novaluenull",
       "isStandalone":false,"deviceInfo":{...},"url":"/sevenVideos/{id}"}
→ {"r":"U2FsdGVkX18..."}          ← CryptoJS 密文
```

- 响应体 `r` 是 **CryptoJS AES**（OpenSSL `Salted__` 格式，口令派生 MD5 → AES-256-CBC）。
- **口令是从 bundle 里直接读到的：`"xxx"`**（另一层 `decrypt_2` 用 `"xxxxx"`）：

```js
decrypt(l){var r=Jg.AES.decrypt(l.r,"xxx"),c=JSON.parse(r.toString(Jg.enc.Utf8));return c}
```

已复现（Node 实现 EVP_BytesToKey(MD5) 即可，与抓包明文一致）：

### VIP 的实际情况：不用破

播放页文案是「此视频有高清版本，立刻开启VIP会员体验」「此视频为会员专享视频，是否开启VIP体验？」，但页面上同时有 **免费线路 / 国内线路 / 高速线路1 / 高速线路2** 四条；`/sevenVideos/{id}` 匿名就返回 `m3u8s[0]` 与 `downloadable:true` —— **免费线路给的就是可直接播的签名 m3u8**，VIP 只控制高清线路与下载按钮。按《VIP处理约定》这属于第 1 条「页面层可绕」，不需要账号。

### 阻止做源的事实：WAF 封 IP

连续探测若干次后，站点对所有端点（含之前可用的 detail）、乃至浏览器直接访问都返回：

```
HTTP 403 {"blocked":true}
页面：抱歉，您的访问已被拦截 …… 参考编号: 02cd0405e1a1d7f3
```

站点前端还有一段专门逻辑：403 + `blocked` → 重试一次 → `navigator.sendBeacon('/js'→'/banned')` 并跳 `/error`。即是说**这是站点主动的 IP 封禁**，不是偶发。API 还有 8 个镜像主机（`v2.cdn199.com` / `kekecdn.net` / `luchu.org` / `madou.ws` / `papapa.biz` / `tianmtv.com` / `xiaoshuo.info` / `xiaoshuo.la`），实测**同一 IP 全部 403**，换主机无效。
