# 新增源：91热爆（resao.com）— VIP 是 CDN 裸奔，不是绕过

2026-10-27 · `sources/video/resao.js`（`resao_video`，视频板块，18+）

## 1. 结论

`https://www.resao.com/` 是 KVS（Kernel Video Sharing）站，**确实有 VIP 专享内容**，但它的 VIP
只挡在「页面层」，**CDN 上的视频文件完全裸奔**：

| 层 | 实测 |
|---|---|
| 页面 | `/private/` = VIP专享，卡片带 `<span class="ico-private">VIP</span>`；游客还有观看次数上限（KVS guest limit），超限后连普通视频页也变成 `<div class="no-player" id="limitplayer">` + 「游客试看已达上限，登入会员以解锁精彩内容！」，**页面里没有 `video_url` / `flashvars` / m3u8** |
| CDN | **不带任何签名就能取**：`https://delivery.douyinpaly.com/hls/contents/videos/{dir}/{id}/{id}.mp4/index.m3u8` → 200 + `#EXTM3U`；`_720p` 变体同样 200；分片 200 + `video/MP2T`；连整片 `…/contents/videos/{dir}/{id}/{id}.mp4` 都能直接下（实测单条 140,814,306 B） |

其中 `dir = floor(id / 1000) * 1000`，并且**页面里那个 `?k=…&t=…` 签名是装饰**——
去掉整段查询串照样 200。

实测覆盖 `/private/` 的 4 条 VIP 片（313374 / 313195 / 313402 / 304908）：

```
313374  默认 9829B master，297 个分片，首片 586,936B video/MP2T；720p 同样 200
313195  默认 511B，12 分片；720p 200
313402  默认 3988B，120 分片；720p 200
304908  默认 2527B，75 分片；720p 200
```

## 2. 所以本源怎么取流

**完全不看页面** —— `content()` 只用 id 现拼 CDN 路径，按「默认 → 720p」顺序探活（校验 `#EXTM3U`）：

```js
dir = floor(id/1000)*1000
候选 = [
  `https://delivery.douyinpaly.com/hls/contents/videos/${dir}/${id}/${id}.mp4/index.m3u8`,
  `https://delivery.douyinpaly.com/hls/contents/videos/${dir}/${id}/${id}_720p.mp4/index.m3u8`,
]
```

好处：

- **游客限流对播放没影响**（限流只影响页面是否内联地址）；
- **VIP 片照样能播**，不需要登录、不需要会员、不需要签名；
- 少一次页面请求，`content()` 通常 0.6 s 出地址。

## 3. 站点结构（抓列表/详情用）

| 用途 | 路径 |
|---|---|
| 最新 / 最多播放 / VIP专享 | `/latest-updates/`、`/most-popular/`、`/private/`，翻页 `{path}2/` |
| 分类 | `/categories/{slug}/`（偷拍 / 探花 / 今日吃瓜 / 国产 / 摄像头 / 无码 …） |
| 搜索 | `/search/?q=关键词`（一页 20 条，无可靠分页） |
| 详情 | `/videos/{id}/{slug}/` ← **必须带 slug**，`/videos/{id}/` 会 404，所以列表项 id 用整条路径，数字 id 在 `content()` 里再抽 |
| 卡片 | `<a href="…/videos/{id}/{slug}/" title="标题" data-rt="…">` + `<img data-original="…/videos_screenshots/{dir}/{id}/320x180/N.jpg">` + 时长 + 播放数 + VIP 徽标 |

  `list` 20 条 `hasMore`、搜索 20 条、`detail` ok、`chapters` 1 条、`content` → CDN m3u8，探活 200；
- **VIP 专项**：只列 `/private/` 时，`content()` 给
  `https://delivery.douyinpaly.com/hls/contents/videos/313000/313374/313374.mp4/index.m3u8`，
  探活 **200 + `#EXTM3U`（9829 B）** —— VIP 片直接可播。

## 5. 限制

- 依赖 `delivery.douyinpaly.com` 这个 CDN 域（站点当前下发的）；它换域时改 `CDN_HOSTS` 即可。
  站点换域的线索：任一视频页里内联的 m3u8 主机名。
- `_1080p` 变体普遍 404（站点只留默认 + 720p），脚本已按这个顺序探测。
- 站内搜索一页 20 条、没有可靠分页标记，`hasMore` 恒 false。
- 全站 18+。
