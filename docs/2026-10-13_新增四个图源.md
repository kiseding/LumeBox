| 站点 | 板块 | 脚本 / id | 接入方式 |
|---|---|---|---|
| https://xman6.com/ | 漫画 | `comic/xman6_comic.js` · `xman6_comic` | 直连可用（MacCMS + conch 主题） |
| https://jcomic.net/ | 漫画 | `comic/jcomic_comic.js` · `jcomic_comic` | 直连可用（正文图是加密串，脚本内解码） |

App 侧配套：展示名字典加了这四个 id；订阅清单（各板块 `sources.js`）加了四条地址。

## 逐站要点（都对着实时页面核过，快照存源仓库 `snapshots/`）

### X漫（xman6.com）
- 列表 `/mcata/{分类}/ob/time/st/all/page/{N}`（24 条/页），封面只在 `data-original`（lazyload）；
  分类从 `/mcata` 导航实时读；搜索 `/msearch/{关键词}/page/{N}`；更新 `/nm`、排行 `/mrank`（`li.ranklist_item` 是另一套标记）。
- 详情页除本作封面外还挂着推荐位封面，封面必须**在 `content_thumb` 块内取**（否则取到别人的）。
- 正文页图片是 `img[data-src]`（懒加载），整页唯一带 `src` 的图是 yandex 统计像素。
- 首页四块串行请求在慢网络下会顶穿沙箱 10s 预算（实测超时过一次），因此改成
  **逐块 try/catch + 6s 软截止**：到点就把已拿到的板块先返回。

### JComic（jcomic.net）
- 列表条目有**两种形态**（同一条列表里混着）：`/eps/{标题}`（多话）与 `/page/{标题}`（单页）。
  因此作品 id **存路径本身**（自带形态信息），标题单独存显示名。
- 标题里的 `/` `～` `+` 在路径里被站点写成 `|A` `|E` `|P` 记号（例：显示名「星期一的丰满/月曜日のたわわ」
  ↔ 路径「星期一的丰满|A月曜日のたわわ」），id 必须原样保留记号，请求时按段编码。
- 正文图是加密串：`data-locked="JCOMIC_TRAPS_{串}"`，真地址 = 去掉前缀、**整串倒序**后 base64 解码。
  脚本自带纯 JS 解码（不赌沙箱有 `atob`）。
- **站点限制（如实说明）**：解出来的图片直链是 **60 秒有效**的 S3 预签名地址
  （`X-Amz-Expires=60`）。列表/详情里拿到的封面放久了会失效（App 显示占位图，重进列表即刷新）；
  一话的正文地址在打开该话时一次性给出，正常连续阅读不受影响。这是站点自身的机制，删掉签名参数只会 403。

### 夜读小说（x-novel.com）
- 列表 `/novels/{N}`（24 条/页）、标签 `/tag/{slug}/{N}`、搜索 `/search?q={kw}&page={N}`；
  分页器是传统「下一页」锚点（注意它在页面中下部，不能只看末尾几 KB）。
- 目录第 1 章有两个坑：底部工具条（「阅读」）与「开始阅读」按钮都指向 `/novel/{id}/1` 且排在目录之前，
  按出现顺序盲取会把第 1 章标题污染成「阅读」——脚本按「含『第 N 章』编号 span 的目录行优先」收集并去噪。
- 详情页上半部分是「按标签逛」的宫格导航（13 项），不能当成本作标签；本作标签是尾部的药丸行。
- 正文取 `article#read-article` 里的 `<p>` 段落，剔除 `div.extra_c_2` 广告块；段落间以空行保留结构。
- 页面里内联着 Cloudflare 的 JS 检测信标（`challenge-platform/scripts/jsd/main.js`），
  **不能**拿 `challenge-platform` 当「被挑战页拦下」的判据（会把每一页都误判成校验页）。

### 金牌影院（jpyy2.com / vv3nwjk.com）
- jpyy2.com 是金牌影院的镜域：302 到主域 www.vv3nwjk.com，同一套后端与 `/api/mw-movie/**` 接口。
- **主域整站在 reCAPTCHA v3 WAF 后面**（521 + `waf_captcha_marker` + `/okokcdn_recaptcha_verify`），
  放行绑浏览器会话与 IP 信誉、没有可复用 Cookie——网页视图过完校验也搬不过来；
  但**手机域 `m.vv3nwjk.com` 的同一套 API 没有这道 WAF**（本轮实测逐接口 200）。脚本按
  「手机域 → 主域 → 镜域」试并记住可用域；三个域全被拦才抛 `WAF_RECAPTCHA_V3`
  （App 据此提示配置 Playwright/Puppeteer 桥接，`LumeSource.bridge`）。
- 接口要签名头：`sign = sha1(md5(参数按 key 升序拼串 + key + t))`，另带 `client-type` / `deviceId` /
  `authorization` / `t`；MD5 与 SHA1 都是脚本内纯 JS 实现。
- **分页参数是 `pageNum`**：传 `page` 实测被接口忽略、永远返回第 1 页（列表与搜索都一样）。
- 播放地址给 1080/720/480 三条 m3u8，默认选**标清**（站点给标清标 `needLogin=false`，
  其它两条标 true；按这个标记挑，不按文案猜——`resolutionName` 是「标清/高清/蓝光」，没有「480」这种数字）。
