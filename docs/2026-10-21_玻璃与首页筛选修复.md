# 玻璃、首页筛选与设置分组

## 本轮变化

- 对照用户 23:52 录屏及 IMG_4049：自绘底栏静止选中态改为低调灰底；按压时背景提亮和降饱和在图标之前处理，选中图标及文字保持原色；去掉主题色外光晕，底座使用细灰边。局部收腰默认 28%，与上层水滴膨胀同步，强度为零可关闭。已有显式配置沿用用户值。
- 修正原生路线：普通 UIBlurEffect 不会自动变为液态玻璃。iOS 26／Xcode 26 接入 UIGlassEffect（标准／清透），厚实及降低透明度使用磨砂；旧系统及旧编译器保留磨砂回退。圆角、应用明暗主题和降低透明度实时同步，原生底座不再叠加自绘渐变和描边。
- 原生视图创建期间发生的配置变化，在创建完成后补发；只更新圆角或主题时不重建材质。切换效果开关不再丢失降低透明度设置。
- 部分脚本在首次列表或首页请求完成后才填充分类筛选。页面现在在该时点补取元数据，并先取分类再取筛选，避免要求用户下拉刷新。切源重置隐藏顶栏；漫画、视频推荐首页及列表保留收缩／回滑显示，猫源顶栏采用同类浮动行为。
- 全局设置整理为七组：个性与界面、导航与首页、阅读与播放、内容与订阅、网络与服务、存储与安全、诊断与关于。保留原入口，清理过时的板块数量描述。

## 验证与边界

新增覆盖：原生视图延迟创建和圆角／主题同步、降低透明度偏好保持、漫画／视频两种首页加载顺序、筛选自动出现及顶栏收缩恢复、GPU 背景提亮至最大时的前景颜色。

出包前全量 Flutter 回归 2119 项通过、12 项跳过，源码及本轮测试静态分析无问题；Impeller 玻璃相关 18 项通过。

原生材质仍是 UIKit 底座与 Flutter 内容的组合，尚未改成系统 UITabBar。平台视图与 Flutter 背景的实际采样、原生光学效果和手感需在用户 iPhone 上验收；桌面预览不能证明与系统电话 App 完全一致。

API 依据：[Apple UIKit 新设计说明](https://developer.apple.com/videos/play/wwdc2025/284/)、[圆角配置](https://developer.apple.com/documentation/uikit/uicornerconfiguration-swift.struct)。
