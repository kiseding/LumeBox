# 音乐首页与音源能力

音乐首页展示继续播放、收藏和历史入口、主题搜索、精选歌单、热门歌曲、新歌及排行榜。推荐来自已启用的音源；不把搜索结果当榜单，也不预装解析脚本。

## 数据入口

- MusicFree：`getRecommendSheetsByTag` + `getMusicSheetInfo` 提供推荐歌单及分页；`getTopLists` + `getTopListDetail` 提供榜单及歌曲。宿主遵循 [MusicFree 插件协议](https://musicfree.catcat.work/plugin/protocol.html)，保留插件返回的完整条目及歌曲标识。
- LX：脚本仍只负责播放地址解析。宿主补充网易云推荐歌单、榜单及酷我热歌/新歌榜；只为脚本声明支持的平台显示对应曲库。其他平台仍可使用搜索。
- 没有推荐能力的源保留搜索入口；没有启用源时显示添加引导，不显示虚构歌曲。

## 生命周期与播放

- 推荐缓存仅驻留内存，10 分钟有效，最多保留 8 组音源组合。切源、停用、删除及用户变量变化会重新加载；失败结果不缓存。退出页面或新请求覆盖旧请求时取消旧请求，过期结果不回写页面。
- 单个源或歌单接口失败不隐藏其他可用内容。详情分页按歌曲标识去重，失败可重试。音源停用后不能继续打开其歌单。
- 继续播放复用现有音频会话，恢复上次队列和当前歌曲的保存进度。点选新歌曲仍从头播放；未新增音频播放器实例。
- 封面使用应用网络传输、取消机制和有界内存缓存，失败回退渐变唱片图案。

## 验证

`flutter test test/music_service_test.dart test/music_page_test.dart test/music_session_test.dart test/music_runtime_test.dart`

覆盖插件桥接、原始标识、分页去重、缓存刷新、源停用、失败隔离、恢复队列、小屏与大字体。平台实时接口另做本地冒烟检查；曲库元数据可访问不代表任意第三方解析脚本都能播放，需要用户安装的音源实际支持对应平台和音质。
