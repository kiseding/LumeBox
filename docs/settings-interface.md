# 设置界面与液态玻璃

2026-10-23。此文记录本轮实际改动及验收边界。

## 设置结构

设置首页只有搜索与七个分类入口，具体功能进入对应二级页。一级、二级页统一使用带图标底板、柔和背景与圆角材质的卡片。小屏单列，大字体允许换行。

| 分类 | 内容 |
|---|---|
| 个性与界面 | 外观、主题色、页面底色、App 图标、应用图标库 |
| 导航与首页 | 自适应颜色、网格标题、内容分类显示、原生系统导航、当前板块图标、液态玻璃管理 |
| 阅读与播放 | 触感反馈、触感强度、后台播放，播放器、音频、图片工具、翻译 |
| 内容与订阅 | 总订阅、源管理、搜索偏好 |
| 网络与服务 | 网络、TMDB、Bangumi |
| 存储与安全 | 缓存、隐私与应用锁、配置备份 |
| 诊断与关于 | 使用说明、沙箱、日志、错误报告、调试与诊断导出、版本 |

外观、网格标题等短选择在页面内操作。主题色和页面底色使用独立色板页，包含界面预览、命名色块与选中反馈。长功能继续进入自己的工具页，避免把所有功能做成抽屉。共享底部选择层改为内容自适应并限制最大高度、避让安全区；长列表仍可扩展和滚动。

首页搜索可直接打开匹配的独立功能，或者进入包含该设置的分类。外观和使用体验等组合功能按分类定位。

使用体验继续读写原 AppPreferences，没有创建第二份触感或后台播放配置。备份页只保留备份操作；使用说明中的路径同步更新。

## 液态玻璃

FrostedSettings 持有通用材质和覆盖配置，仍写入原 frosted_settings.json，现有配置备份已经包含该文件。调节即时预览，滑块结束时原子保存；不在每个拖动帧写盘。

通用参数共 14 项：背景模糊、底色浓度、主题色融入、背景饱和度、边缘亮度、边缘厚度、表面高光、投影浓度、投影柔和度、圆角比例、按压下沉、过渡时长、按压透镜折射、按压边缘色散。参数读取会校验有限数并限制范围。

管理页可以选择模块和部件，配置按下列优先级继承：

1. 当前模块、当前部件。
2. 当前模块的全部部件。
3. 全 App 的当前部件。
4. 全 App 通用配置或内置默认值。

首次修改继承范围会生成独立配置快照。重置当前范围会删除该覆盖并重新继承，不清除其他范围。管理页仅展示当前部件支持的参数，底栏的其他液态细节进入“底栏液态动效”中的实际导航预览调整。

底栏保留水滴鼓起、胶囊联动、清透、折射、拖尾、高光、弹性阻尼、基础形状、自由形变、原生/自绘渲染等既有细分参数，并补齐回弹时长入口。全局毛玻璃与减少透明效果对自绘底栏同步生效。原生系统导航的材质由系统决定，不能承诺 Flutter 参数可更改所有系统效果。

底栏尺寸与位置页提供高度（40–150）、自动/指定宽度（120–1000）、独立左右边距（0–100）、横向偏移（±100）、纵向偏移（±80）及离安全区距离（−50–100）。超出可用屏幕时限制实际尺寸和偏移，内容避让同步更新；仅重置几何时不影响液态参数。页面内包含默认参照图片和当前可交互预览；图片由真实 Flutter 默认组件本地渲染，不是真机截图。原生系统导航启用时明确提示这些尺寸仅适用于自绘底栏。

## 接入范围与迁移

共享 GlassCard、GlassPanel、GlassAppBar、底部 Dock、漫画阅读控件、播放器控制条与弹幕面板接入相同配置。光学层采样背景，正文和图片、视频画面本身不套滤镜；按压透镜只用于可点击表面。减少动态效果时停止此类按压动效；高对比度或减少透明效果时使用实色表面。没有强制替换第三方网页内容或原生系统控件的绘制。

旧悬浮模块页面删除，旧位移和材质数据不再作为新共享材质的来源。旧导航管理的排序、显隐和收起球自定义入口移除；读取旧 shell 配置时恢复默认页签顺序与可见性。尺寸与位置现在集中到液态玻璃管理，保留并校验持久化值。旧悬浮模块位移不再生效。

导航图标编辑复用既有 dock 图标槽与图标库。它作用于应用自绘导航，原生系统导航仍由系统使用其支持的图标表现。
