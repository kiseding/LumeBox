# 导入源后滑动与切页卡顿

## 诊断范围

用户提供的诊断包来自 App 1.0.214（214）、iOS 27.0.1，保存漫画板块 53 个源、视频板块 95 个源。最近日志中有 417 条包含“请求已取消”的记录，包含大量重复堆栈。包中没有逐帧耗时或主线程采样，因此这些记录用于定位代码路径，不能单独证明真机卡顿的全部原因。

诊断原包、配置、请求地址和凭据不纳入仓库。

## 已修复的阻塞路径

1. App 每分钟自动同步原先传入 `force: true`，跳过订阅自身的六小时检查间隔。改为遵守间隔；用户手动更新仍可强制刷新。
2. 更新已有未读通知的源时，每个源各自递增订阅 revision；探索页面监听 revision 后立即重载、取消在途请求。改为整批同步结束统一保存变更通知、递增一次 revision。未变化的脚本不触发重载。
3. 每次列举源都在 UI isolate 重复扫描完整脚本，提取运行时、媒体类型、内容分类、站点和图标。新增有容量限制的脚本展示信息缓存，首次批量解析交给 worker isolate。缓存按板块、源 ID 和实际脚本内容匹配，同版本脚本变化也会失效；启用状态、网络、用户配置等仍读取当前记录。
4. 源排序原先在比较器的每次调用中读取 SQLite、重建完整顺序并线性查找。改为每次排序先读取一次顺序，生成 ID 排名；置顶信息也提前读取。覆盖漫画、视频、源管理和猫源选择。
5. 图片头声明的 AES/Fernet 解密及旧 `lume-enc` ECB/CBC 解密移至 worker isolate；普通图片直接通过。旧格式的多块解密、内联 data URI 和失败回退继续保留。
6. 页面请求取消原先在沙箱被记录为引擎异常，在 JS 数据源适配器又被包装成源错误。现在保留 `NetworkCancelled` 类型，已取消的排队任务不执行脚本，探索页面不再为正常切页取消输出错误堆栈。真正的脚本失败、超时仍按原有错误路径处理。

修改后的首次列表总耗时仍包含 worker 启动和解析；该解析已不占用 UI isolate，相关测试验证解析期间 UI 事件能执行。后续调用复用缓存，列表耗时包含数据库读取和描述符组装。

相关 26 个测试文件合计 **235 项通过**。涵盖 150 源首次导入、已有未读变更的批量更新、无变化同步、通知落盘、同版本脚本缓存失效、并发缓存读取、缓存容量上限、加密图多块还原、沙箱排队/在途取消、真正的脚本失败、置顶与过滤后拖拽、探索筛选、路由恢复、网络生命周期及图标回退。修改涉及的 20 个 Dart 文件静态分析无问题。

## 安装验收

本轮修改属于 App，更新源订阅不能替换这些 Dart 逻辑，需要从包含本次提交的 `main` 重新构建并安装 IPA。构建流程为手动触发，推送本身不会自动生成 IPA。

真机验收仍需检查：保留现有 148 个源，导入完成后连续滑动和切换漫画/视频页面；在源选择中搜索、置顶、拖动；批量更新时观察当前列表是否只在完成后刷新一次；打开带加密封面的源确认图片正常。现有诊断未提供帧耗时采样，也未直接连接用户手机，本轮不宣称已完成真机性能验收。

## 继续排查：滚动、缓存与翻译

用户继续要求检查，并反馈“已翻译 0、未完成 109、原文保留 13”。这表示该次任务没有得到可替换的译文，13 条原文保留不能算作已翻译；不是页面只能翻译 100 条。当前诊断配置为自动识别原文、简体中文目标、AI 模式，日志未记录该张截图对应的接口响应，不能据此断言具体是哪一家服务或哪一种语言失败。

继续修复的路径：

- 探索网格、列表的每个 `itemBuilder` 原先重新计算 `_sortedItems`，扫描全部条目、为可见性检查计算资源哈希，并重复排序。改为一次页面构建生成一个快照，滚动创建卡片复用快照；翻页、排序或资料库变动仍会重建快照。
- 图片预载缓存改为异步读写、异步列目录和读取文件属性；淘汰时按已读取的修改时间排序，比较器内不再反复访问磁盘。写入与清理串行，并在排队执行时再次核对 generation，防止清理后旧任务重新写回。
- 译文缓存加载、序列化和大小裁剪放到 worker；译文键的 SHA-256 结果使用有上限的缓存，减少卡片重建时重复计算。翻译按钮也复用去重文本，单次统计复用查找结果。
- AI 请求拆成每批至多 20 条、通常至多 6000 字符。只对返回原文或空译文的条目补试一次；某批失败保留其它批的成功译文。认证、地址、限流等错误终止该轮后续请求，错误提示区分 HTTP、截断、空结果、未返回有效译文等情况。不会用原文冒充译文。
- 系统翻译逐条捕获失败，保留同语种已完成内容；取消任务使用独立取消错误码，避免取消后触发 AI 补译。
- 翻译诊断只记录模式、语言、数量和错误类型，不记录原文、译文、接口凭据。

补充翻译、缓存与浏览回归最终 129 项通过；播放、封面加载、预载管理和 122 条页面翻译另组 35 项通过，涉及本次修改的 13 个 Dart 文件静态分析无问题。旧播放测试替身改为提供稳定的画面尺寸，剧集定位按实际剧集键匹配，避免把装饰边框算作剧集。外部翻译服务仍可能返回原文、拒绝内容或发生网络错误，本轮验证使用模拟服务，不宣称已验证用户真实接口的全部内容。

iOS 原生检查发现工作流的独立 Swift 校验仍使用 iOS 13 目标，而 Xcode 项目和底栏模拟器检查均已使用 iOS 15。已把独立校验同步为 iOS 15，避免对底栏 `scrollEdgeAppearance` 产生错误的可用性失败。
