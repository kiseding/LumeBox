## 2. 已交付两个源的实现要点

### 爱播爱播 `sources/video/aiboaibo.js`（`aiboaibo_video`）

- 首页解析 SSR 内嵌对象（正则取 `id/name/pic/m3u8`），列表与搜索共用一份 10 分钟缓存；
- `content()` 直接返回该条的 m3u8（**不需要详情页**），实测 `sryndbsfvd.com/20261027/5Lxq68MZ/index.m3u8` 探活 **200 + #EXTM3U（119 B master，1920x1080）**；
- 限制：服务端只给 12 条、翻页参数无效；老条目只能靠搜索命中（搜索是 SSR 页面，同样解析内嵌 list）。

### 海角情 `sources/video/haijiaoqing.js`（`haijiaoqing_video`）

- 列表/详情走 `wp-json`（`X-WP-Total` / `X-WP-TotalPages` 可读，分页稳定）；
- 正文取 `<iframe>` 列表 → `chapters` 按「播放源 1..N」，`content()` 返回 `kind: webplayer`；
- 封面取正文首个 `<img>`（这个站多是 gif 预览图，部分帖子为 0 张时留空）；
- 限制：播放器页 `player.abyssplayer.com/{code}` 是 JS 渲染，HTML 里没有 m3u8（我试过 `/{code}.json`、`/api/v1/videos/{code}`、`/api/{code}` 均无），所以直连取流需要继续逆向该播放器；当前按网页播放交付。

## 4. 两个 Cloudflare 挑战站的说明

`hsex.men` 与 `reddxxx.com` 不是"解析没写"，而是**响应就是挑战页**：`cf-mitigated: challenge`、页面标题 `Just a moment...`。LumeSource 的 `LumeSource.http` 是原生 HTTP 客户端，执行不了 JS 挑战，所以：
- 要么放弃（当前选择）；
- 要么给这两个站单独做「浏览器内核源」（超出当前源框架，需要 App 侧支持）。
