# LumeBox 1.0.179 测试包

版本 1.0.179（build 179），源代码提交 `d876c3fb7d67104cfceb0f08da7204a965d7a565`。

构建：[GitHub Actions](https://github.com/teng662858/LumeBox/actions/runs/39457664609)。未签名 IPA，需要按以往方式使用自己的证书重签名安装。包体路径、大小和 SHA256 以同目录校验记录为准。

## 包含的修改

- 漫画、视频、设置三个底部入口；猫源归视频源选择器。
- Python 多文件与依赖、代理及模块源链路；经典 Rex 明文 Widget 与集合导入。REXENC／FWENC 加密脚本尚未接通，不能把导入成功当作可播放。
- 弹弹play 统一凭证、连接测试、保存后播放器重载和具体错误提示。
- 紧凑顶栏：源切换、文字历史收藏、快捷布局按钮、右下搜索；管理和订阅收进源抽屉。
- 全局封面单行标题、统一留白与 12 间距；调整应用字号时主要浏览控件保持尺寸。
- 首页／列表加载后自动补齐分类筛选；推荐首页、普通列表及猫源保留收缩顶栏。
- 玻璃背景提亮与前景颜色分离、静止选中灰底、轻微收腰和水滴膨胀；iOS 26 原生模式接入 UIGlassEffect。
- 全局设置整理为七组，保留原入口。

## 建议先测

1. 漫画和视频分别切换普通源、Python／模块源、猫源，确认分类筛选自动出现；上滑收起顶栏、回滑恢复。
2. 字号从 100% 调到 160%，观察源切换栏、封面、列表行及标题；再检查历史和收藏。
3. 设置 → 底部导航栏管理 → 液态玻璃细调，先选推荐预设，按住和拖动底栏；确认局部内收、水滴膨胀、图标颜色和松手复位。已有手动参数保留，收腰强度为 0 时不会内收。
4. iOS 26 可切换“iOS 原生材质”的标准／清透模式，对比浅色、深色和彩色封面背景。原生模式仍是系统底座与 Flutter 内容组合，自绘透镜折射不在该模式运行；旧系统和厚实风格使用磨砂。
5. 弹幕源里保存弹弹play ID／密钥并测试连接，再打开已知有弹幕的具体剧集。失败时记录界面的错误原文。

本机全量测试 2119 项通过、12 项跳过；Impeller 玻璃专项 18 项通过，静态分析无问题。真机视觉、脚本真实站点和用户弹幕账户仍需本包验收。
