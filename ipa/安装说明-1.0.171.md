## 在 iPhone 上对比 A/B

1. 安装后打开：**设置 → 底部导航栏管理 → 液态玻璃细调**；
2. “渲染方式（A/B 对比）”切换：
   - `Flutter 自绘`（A，默认）：完整自绘透镜、清澈、色散、形状；
   - `iOS 原生材质`（B）：系统 `UIVisualEffectView` 底座（iOS 26 自动 Liquid Glass 外观），出现“原生材质参数”（清透/标准/厚实 + 原生材质白度）；
3. 按住/拖动底栏，滚动浅色空白、文字、彩色封面、视频等背景对比；
4. 也可以在系统设置里切换“增强对比度/降低透明度”，观察底栏是否立即变化。

| 对比项 | 看什么 |
| --- | --- |
| 底座材质 | 磨砂/通透程度、颜色透出、与内容层次 |
| 透镜 | A 有自绘放大/折射/色散；B 关闭自绘透镜折射（平台视图限制），主要看底座 |
| 按压反馈 | 整条放大 + 变白是否符合预期 |
| 拖动 | 跟手、拉伸、拖尾、回弹是否连续 |
| 可读性 | 浅色/深色、彩色封面上的图标文字对比度 |

## 已知限制

- 未签名包，必须重签名；直接安装会失败；
- iOS 原生材质模式是“原生材质底座 + Flutter 图标文字”，不是完整原生 TabBar；B 模式会关闭自绘透镜折射；
- 旧 iOS 上原生材质是系统磨砂，不一定有 iOS 26 Liquid Glass 外观；
- 本机测试结论不代表真机光学、手感与帧耗时已达标，需要实测反馈；
- 若安装后闪退，请提供 iOS 版本、机型与安装方式（签名工具）。
